# 第九至十一步｜提示词自检清单

- 项目：
- 适用资产：
- 版本：S9-S11-v2

> 本表不直接输出给用户，是生成成品提示词前的内部核对表。核对通过后再按 `templates/standardized-prompts.md` 合成一段式正文。
>
> 现代或科幻项目：先按 `standardized-prompts.md` 的「题材槽位替换表」替换槽位，再逐项核对本表。表中出现"朝代""形制""古装"等词处，按替换表理解为等价项。

## 一、通用自检（三类资产都适用）

| # | 检查项 | 通过 |
|---|---|---|
| 1 | 正文只引用一个风格卡 ID 与定稿版本，没有混入第二个风格来源 |  |
| 2 | 资产编号与第四步锁定值一致，未重命名 |  |
| 3 | 正文不含 `[来源]/[设定]/[推断]/[创作]` 标签，标注只留在正文外 |  |
| 4 | 材质写成具体名称（麻/绢/锦/木/铁/铜/陶），不用“布料”“金属”这类泛称 |  |
| 5 | 使用痕迹、磨损、氧化等具体到位置，不写“做旧感” |  |
| 6 | 统一负面词与资产特有负面词都已写入 |  |
| 7 | 没有把成片戏剧光影写进风格浅色底展示图 |  |
| 8 | 本段正文可直接粘贴使用，不需要用户自行拼接字段 |  |
| 9 | 已拼接生图边界 DO/AVOID（`templates/generation-boundary.md`） |  |

## 二、角色图专项

| # | 检查项 | 通过 |
|---|---|---|
| 1 | 角色卡为 6:5 整卡（1920×1600），**五区齐备**：顶栏约 7%／上半区约 60%（25% 半身主视觉＋75% 三视图）／下半区约 33%（30% 六行信息表＋70% 四格细节特写）；②③ 未写成「纵向通高」 |  |
| 2 | 主视觉为**半身**（自头顶裁到腰胯）、正面**脸部完整不遮**、情绪自然；三视图为正/侧/后全身，各带角标 |  |
| 2b | **三视图正、侧视图的面部灰圆遮罩已写明**：纯色中性灰（约 #8C8C8C）、直径约面部宽 1.2 倍、盖满眉/眼/鼻/口、无渐变无投影、不盖发巾与颈项、三张同灰值同直径；后视图不写遮罩 |  |
| 3 | 角色信息为六行键值表（姓名／年代·身份／年龄·籍贯／性格／外貌·发型／着装·气质），与 S2/S4 一致，缺项写「不详」 |  |
| 4 | 四格细节特写均有标签（左侧面／右侧面／右眼部极度近景／后面发型），无空格 |  |
| 5 | 提示词**逐区点名了占比与内容**，没有留「由模型合理排布」「不强制分格」这类让步表述 |  |
| 6 | 已写明三视图与主视觉为**同一人同一造型同一光线**（发式／服装／体型一致即可，面部已遮无需比对）；四格特写从主视觉取景、不新增人物 |  |
| 7 | 明确写了“不拿与设定无关的道具” |  |
| 8 | 顶栏含造型字母与形制一句话；卡内文字仅限顶栏、各区标题、四格标签与信息表，**② 主视觉区内无任何文字与色块**（多出的文字行会落进故事板取图范围，让去背失败） |  |
| 9 | 本张只含一个造型，没有把两个造型拼进同一张 |  |
| 10 | 已写明该造型的出场场次，能与第四步造型清单对上 |  |
| 11 | 该造型已在造型清单登记，不是临时新增 |  |
| 12 | 本造型 **1 张 6:5 角色卡**，由一段提示词一次生图，不分张、不合图、不裁切分发 |  |

| # | 检查项 | 通过 |
|---|---|---|

| 2 | 卡面为 **左二右四六格**：左列约 64% 宽（上 V01 微缩全景、下 V02 人眼视角），右列约 34% 宽四格竖排 |  |
