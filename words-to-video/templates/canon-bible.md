# 第二步｜人物深度与弧光 ＋ 前史与世界观（Canon Bible）

- 项目：
- 版本：

> 设定集解决一件事：**后面每一步吵架的时候，拿什么当裁判。**
> 它只写"这个世界里什么成立、谁想干什么、哪些东西不能变"，不写分镜、不写台词。
>
> **本步建造的是"在故事开始之前就已经运行了很久"的那个世界。** 角色不是从出生演起——他们带着前史走进第一场戏，关系的既往已经存在，世界的规则早已生效。编剧的工作是先建造这个完整世界，再从最有张力的截面切入（第三步结构大纲）。
>
> 与 `information-extraction.md` 的分工：**仅改编项目**先用那份表抓取"来源里有什么"作为输入；本文件确定"项目里承认什么"。**原创项目跳过那份表**，直接在本文建世界——没有来源文本可抓时不要空转那张表。

## 一、世界规则

只写**会约束人物行动**的规则。写在背景里好看、但不影响任何选择的设定，属于装饰，删掉或降级为 `[推断]`。

| 编号 | 规则 | 类型 | 来源 | 会怎样约束行动 |
|---|---|---|---|---|
| W01 |  | 物理/技术/社会/制度/超自然 | `[来源]`/`[设定]`/`[创作]` | 具体到"因此某人不能做某事" |

类型说明：

- **物理**：重力、时间流速、环境极限
- **技术**：能做什么、做不到什么、代价是什么
- **社会**：阶层、职业、禁忌、称谓
- **制度**：法律、组织、流程、权限
- **超自然**：能力、代价、触发条件、不可逆后果

自检：把每条规则念一遍，如果删掉它，人物的选择完全不变，那它就不是规则。

### 世界观三层（科幻 / 复杂世界建议填写，当代现实可略）

只写「会约束行动的规则」容易平铺。复杂世界按三层展开，让"规则 → 逻辑 → 真相"有纵深：

| 层 | 内容 | 任务 |
|---|---|---|
| 表层规则 | 观众一眼可见的运转方式（如"出行靠轨道胶囊"） | 建立可拍的日常 |
| 运行逻辑 | 表层之下的因果（如"胶囊由中央调度，个体无路线权"） | 制造可违反 / 可依赖的系统 |
| 底层真相 | 系统真正服务什么（如"调度算法在替某人保留逃生位"） | 给结局反转或代价以根基 |

**信息释放时间表**（配套）：规划"第几分钟让观众知道哪一层"，避免开场倾泻或结尾硬塞。每层释放都应有可拍的落点。

规则：

- **want 与 need 必须不同**，否则人物没有内在张力，只有任务。
- **阻力必须可拍**：写"父亲的期待"不是阻力，写"父亲每天在同一时刻打来电话，而他不接"才是。
- `original` 模式下这些全部是 `[创作]`；`adaptation` 模式下只能从来源推导的标 `[推断]`，明确超出原作的标 `[创作]`。
- **Ghost/Lie/Flaw/矛盾性 为可选深度列**，仅供第三步剧本层塑造冲突、破绽（tell）与潜台词空间；**不进入第四步资产卡六行信息表**（姓名／身份／年龄／性格／外貌／着装），避免下游卡 schema 变动。
- **次要角色必须标注功能**（镜像／催化／主题／节奏，至少一个），无功能者合并或删除；此项标记只进剧本层，**不进入资产卡六行表**（详见 `references/storycraft.md` 第四节）。

### 前史：角色带着什么走进第一场戏

为每个主要角色写 1–3 条**已经发生过、且仍在扭曲当下选择**的过往。只写事件与后果，**不写心理、不写感悟**。前史的作用不是解释人物，而是让他在第一场戏里就已经是"有来历的人"。

| 角色 | 前史事件（已发生） | 它如何扭曲当下的选择 |
|---|---|---|
|  |  |  |

> 前史不进对白。人物不会在片中谈论这些——它们只通过选择、回避、习惯动作与破绽（tell）泄漏出来。短片可精简到每人 1 条；长内容须充分展开。**如非必要不用闪回**。

### 横截面切入点（山音第四步第四项）

故事不从人物出生讲起——**先建造已经在运行的世界，再从最有张力的截面切入**。在此写清：

| 项 | 内容 |
|---|---|
| 时代 / 环境背景 | 什么时代、什么环境、什么社会氛围 |
| **为什么从这个时刻开始讲** | 这个时刻有什么特殊性？它之前世界已经运行了多久？ |
| 第一场戏里观众能看到的"已经运行很久"的痕迹 | 具体可见的物、习惯、秩序（不是旁白交代） |
| 观众此刻不知道、但需要知道的前史 | 交给第三步用对白与视觉线索自然散落，不集中交代 |

## 五、声音与说话人

决定"谁的声音、说多快、有没有音乐"。写在这里而不是留到提示词阶段，原因是这三项一旦中途改，前面所有段落的提示词都要重写。

| 项 | 内容 |
|---|---|
| 说话人 ID | `S1`、`S2`……一个角色一个 ID，全片不变；换装不换 ID |
| 音色 | 每个 ID 一句具体描述（如"低而稳的女声，克制，句尾不下压"），不写"好听""有磁性" |
| 语速基调 | 每个 ID 的默认字/秒区间，供第七步核算时取用 |
| 台词语言 | 普通话／方言／文言朗读／全片无对白 |
| 台词承载方式 | 常规对白（同期声、口型对应）／原文吟诵（画外声、口型不对应）／演唱／全片无对白。**这是音频层选择，不是内容类型**；原文原句想一字不改时用吟诵，不要改写成白话对白 |
| 背景音乐 | 默认 **无**。本平台 `non_diegetic_music` 固定写 `N/A`；确实需要配乐时在此登记，并写明后期如何加入 |
| 环境音基调 | 本片的底噪与空间感（如"室内日光灯底噪＋远处街道"），供第八步 `overall_soundscape` 起手 |

规则：

- 说话人 ID 一经分配，第八步提示词与第十四步填表包都用它，**不得中途换号**。
- 无对白项目也要明确写"全片无对白"，不留空——留空会被当成"还没想好"，后面会有人回来补台词。
- 语速基调是**建议区间**，第七步按具体镜头时长与字数核算，不以基调代替核算。

## 六、视觉连续性锁

跨场次不得变化、一旦变化必须给出原因的可见事实。

| 锁 | 内容 | 允许变化的条件 |
|---|---|---|
| 角色外形 | 发型、体型、面部特征 | 不随时间变化 |
| 造型 | 服装、配饰、随身物 | 换装须有场次内可见原因（雨淋、更衣、时间跳跃） |
| 伤势/污损 | 出现位置、进度 | 只能单向累积，不得无故消失 |
| 持物 | 手里拿什么 | 交接必须在画面里发生 |
| 场景结构 | 门窗位置、陈设方位、光源方向 | 不变化 |
| 时代/科技痕迹 | 器物、界面、载具的等级 | 不跳级 |

**身份与变体要分开记**：换衣服不是换人，伤势与持物可以随剧情变。凡"看起来像换了个人"的变化，都要在这里先登记。
