## 二、核心戏剧动作（破题）

**这是 S0 的主产出。** 故事的"核"＝一个可拍的戏剧动作，不是主题、不是情绪、不是一句话氛围。

### 方案格式（山音口径：先给 3–5 个方案，用户选定后再往下走）

用户已有构思时直接用；没有明确想法时，按下面的格式一次性给出 3–5 个方案（每个方案都是一条完整的戏剧动作，不是三个角度的同一个故事）：

```
* 方案 A/B/C：
  * 主角：
  * 目标（Want）：        ← 必须有急切性，他现在就要，不能等
  * 阻碍（Conflict）：    ← 必须与目标直接对抗，且可拍
  * 一句话 logline：
```

**用户选定一个方案后**，把它的四项（＋代价）填进下表并锁定——下表是最终交付口径，方案表只是选型过程：

| 项 | 内容 |
|---|---|
| **谁（主体）** | 具体的人，不是"一群人" |
| **想要什么（目标）** | 必须有急切性——他现在就要，不能等 |
| **被什么挡住（阻碍）** | 必须与目标直接对抗，且可拍（不是抽象的"命运""内心"） |
| **代价是什么** | 得不到会失去什么／得到要付出什么 |
| **一句话 logline** | 谁，在什么处境下，想要什么，被什么挡住 |

自检（山音「核心概念与戏剧动作」三条）：

- [ ] 是否建立了"目标 ＋ 阻碍"？目标是否合理且急切？
- [ ] 阻碍是否与目标有强烈对抗关系？冲突是否是驱动故事的发动机？
- [ ] 阻碍是否在合理尺度内、而非刻意夸大？（**阻碍不与目标直接对抗，这不是戏剧动作，是情境**；代价为空，观众不知道该担心什么）

> 一句话或梗概类输入通常**只含情境、不含动作**（"雨夜，外卖员在桥上停了很久"是画面，不是戏剧动作）。此时用 `references/ideation-toolkit.md` 把它锐化成"目标＋阻碍"，**不把方法论当菜单展示给用户**。

| 字段 | 内容 |

| 视频内容类型 | `剧情演绎` / `MV`（只此两种，按第六节建议） |
| 受众 |  |
| 目标平台与用途 |  |
| 调性 | 与上栏轴④一致，此处只复述成一句人话（冷/暖、克制/浓烈、写实/风格化），**不另立一套说法** |
| 结局倾向 | 闭合 / 留白 / 反转 / 苦涩 |

> **题材怎么写**：四轴定位（时代世界／类型片／地域／调性）见 `references/genres/taxonomy.md`，取值是开放集，可自造。不要用"古风""赛博感""氛围感"这类词充当题材定稿——它们既不是题材也不是风格卡，最后会落不了地。
>
> **四轴写全之后，题材包才有加载依据**：只有轴①落在历史或历史向架空时才考虑古典考据；轴③决定地域质感词；轴④直接进风格卡第④⑤维。
>
> **"题材包（可 0 份）"是允许的。** 四轴写得够清楚时，一份包都不带也能往下走——包的作用只是提供那份题材特有的世界规则清单、视觉词汇与常见失败清单。只有确定要往那个深水区走才加载，不要为了"看起来规矩"挂一份用不上的包。

## 六、视频内容类型的建议规则

**内容类型只有两种，先判定属于哪一种，再谈其他。**

| 类型 | 靠什么推进 | 观众为什么看下去 | 判断信号 |
|---|---|---|---|
| `剧情演绎` | 事件、人物行动、对白 | 想知道"接下来会怎样" | 有明确的人物欲望、阻力与结果 |
| `MV` | 音乐、节奏、意象段落 | 被情绪与韵律带着走 | 没有完整事件，成立的是情绪线 |

用户未指定内容类型时，按来源形态给出**一个主推 + 一个备选**，说明推荐理由、补全量与局限：

| 来源形态 | 主推 | 备选 | 关键限制 |
|---|---|---|---|
| 短诗、词曲 | `MV` | `剧情演绎`（辅以原文吟诵） | 20–40 字撑不起事件链，MV 靠画面与韵律承载；走剧情演绎须补建一个最小事件，补建部分标 `[创作]` |
| 叙事诗、文言短文 | `剧情演绎` | `MV` | 台词需自行改写，改写部分标 `[创作]`；想保留原文原句时改用吟诵承载，不改字 |
| 古典小说片段 | `剧情演绎` | — | 信息量大，1–3 分钟只能取一个事件 |
| 一句话、梗概 | `剧情演绎` | — | 事件容量不足时必须补建冲突，全部标 `[创作]`；不用 `MV` 回避叙事 |
| 已有剧本 | 按剧本类型 | — | 不改结构，只做视觉化 |

### 音频层（不属于内容类型）

原文吟诵、改编歌曲、配乐这三件事，过去被写成内容类型的一部分，实际是**同一部片子用什么声音**的问题，与"剧情演绎 / MV"是两个独立维度。三项在设定集的声音与说话人节登记：

| 项 | 可选值 |
|---|---|
| 台词承载方式 | 常规对白 / 原文吟诵（画外声，口型不对应）/ 演唱 / 全片无对白 |
| 背景音乐 | 无（默认）/ 有，且写明后期如何加入 |

约束：

- `MV` 通常需要音乐，但**本平台 `non_diegetic_music` 固定写 `N/A`**，音乐须登记为后期加入，不指望一次生成带乐。
- 选了"演唱"就要同时处理歌词与调性，歌词属 `[创作]`。
- 一个项目只能有一个内容类型，不允许"前半段剧情、后半段 MV"这种混合；需要交替时按 `剧情演绎` 处理，把意象段落写成无对白的段落。
