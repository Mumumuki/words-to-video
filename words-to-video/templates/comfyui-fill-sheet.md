### 未使用的槽位

**编号可以不连续**：常见情形是某段用 1、2、3、6，中间的 4、5 留给别的段落——这是正常的，编号是整集统一的资产身份，不是段内顺序。按本段实际在用的槽位填，**没用的槽位留空并标「本段不用」**，不要为了让序号连续而重排编号。

| 本段未用到的槽位（逐个列出） | 不连节点／载空白（按工作流要求二选一，此处记明）；不生成对应文件 |

## 七、提交前检查

**内容层**

- [ ] 六字段齐全、顺序正确、无缺项
- [ ] Shot 数 = 分镜表镜头数（**≤ 本段格数 N**），时间码逐镜对应，且每个切换点落在格分界线上
- [ ] 每镜出现人物都重复了服装关键词
- [ ] 有台词的镜头，说话人即画面主体
- [ ] 每句台词前有语速，气口处有 `pause ~0.8s`
- [ ] `non_diegetic_music` 为 `N/A`
- [ ] 台词与第七步分镜表逐字一致，未被改写

**衔接层**

- [ ] **承接五项对齐**：本段首帧与上一段末帧在**人物、服装、位置、光位、构图方向**上都接得上（比对 `handoff/P00-last.png` 与本段 `P01-first.png`）
- [ ] `handoff/` 两帧已落盘（`P0N-first.png`、`P0N-last.png`），比例与成片一致，**没有误塞进 9 个参考槽**
- [ ] `retention_analysis` 里有 `<Continuity>` 行：首段写 `none`，其余写明接的是上一段哪一帧
- [ ] `retention_analysis` 已写清本段保留了什么、替换了什么，**没有"同前""照旧"这类指代**

**文件层**

- [ ] `refs/` 文件名以 `PictureN_` 开头，**`N` 与本表、与 `prompt.txt` 里的编号逐个对得上**；本段没用的槽位不生成文件，也不为凑连续而重编号
- [ ] 图片取自资产卡取用区，**未额外生成**
- [ ] 图片内容与 Picture 表里的资产编号一致（错一张，全段漂）
- [ ] 时长参数不大于本段实际时长

**成本层**

- [ ] 已告知用户本次提交的预计消耗
- [ ] 用户已明确同意提交

### 未通过时的归因指引

| 现象 | 先改哪一层 |
|---|---|
| 服装、发型、配饰漂移 | 提示词（三层加固是否每镜都写了） |
| 位置漂移、座位错乱 | 提示词（位置锁定 ＋ 空间锚点） |
| 人物长相对不上 | 参考图（Picture 是否挂错、是否裁到了无脸区域） |
| 台词时间不够、吞字 | 第七步语速，不在提示词层硬压 |
| 画面风格不统一 | 提示词（曝光统一前缀是否写了） |
| 分镜顺序乱、少镜多镜 | 第七步分镜表 |
| 报错、超时、无输出 | 参数与工作流 |

> **一次只改一层。** 同时改提示词和参考图，出问题后无法归因。
