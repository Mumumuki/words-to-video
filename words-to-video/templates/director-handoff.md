| 每段关键帧数 |  | N 个（默认 6，下限 2；不足按补帧规则补，补不出有戏剧依据的就按实际 N 格出板，不凑满、不留空） |
| 每段镜头数 |  | 本段格数 N 个以内（N 默认 6，下限 2）。一格不能跨两镜、每镜至少占一格，故格子数即镜头数上限；超出的段落必须拆段 |
| 段间承接 |  | **每段都接上一段**：段界落在硬切点或动作完成点，本段首帧须与上段末帧在人物、服装、位置、光位、构图方向五项上接得上（详见 `references/platforms/comfyui-minimax.md` 第二节「段落承接链」） |

> 段落是故事板的装载单位：一段对应**一套**故事板（`SB-0N`），N 个关键帧（默认 6，下限 2）在本段时长内讲完这一小段戏。全片故事板**套数** ≈ 总时长 ÷ 段落时长（默认 15 秒）。**每套必出两版式两张**（`table` 六区段落板·给人看／`raw` 模型版·给视频模型），由同一批 N 张无字 cells 拼版产出，故图张数＝套数 × 2，请在分镜阶段一次规划到位。
>
> **格镜对齐**：N 格时间码首尾相接铺满整段、每格完整落在同一镜内（切点即格分界线）。这条在第七步随分镜定死，第十二步按自检 B19 复核；两端任一处改动都要同步另一处。

## 三·补 核心视听手法（S6 定，S7 落）

> 本节的武器库与选择原则见 `references/director-visual-language.md`「Audio-Visual Device Library」，剧本层的意图标记见 `references/storycraft.md` 第七节。**S6 在这里选定，S7 落到分镜字段**，不留给第十二步临时发挥。

**一部片子只选 1–2 种核心手法。** 手法必须服务本片概念与核心戏剧动作——不是"想用分屏所以用了分屏"。选定后在括号里写清它落在哪些段落、怎么递进。

| 项 | 内容 |
|---|---|
| 核心手法 1 | 名称 ＋ 用在哪些段（如 `P01`／`P03`） |
| 它为什么契合本片概念 | 一句话，说不出理由就换一种 |
| 递进方式 | 升级（单分屏→四分屏）／变异（正放→倒放）／结尾被打破（全片固定机位，最后一镜突然移动） |
| 是否承担翻转 | 否／是（是则写明翻转发生在哪一段、形式怎么变） |
| 落到哪些分镜字段 | 景别／角度／运镜／衔接／音效／镜头级约束（逐项点名，保证 S7 不会漏） |
| 核心手法 2（可选） | 同上；没有就写"无" |

自检：

- [ ] 只选了 1–2 种，没有堆成炫技集锦？
- [ ] 每种都能说出"它为什么服务这个概念"？
- [ ] 递进方式已写明（不会从头到尾一个样）？
- [ ] 手法在本平台单段内可闭合（不依赖跨段才成立的效果）？
- [ ] 与风格卡第③④⑤维不冲突（如色彩限制须回写风格卡）？

> 选定后同步三处：本表、S7 分镜表的对应字段、第八步六段式的 `detailed_description`。**任一处漏写，生图与出片就会各说各话。**
