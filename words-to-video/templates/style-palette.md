# 资产板与故事板 · 外壳配色与艺术字映射

- 版本：PALETTE-v1
- 依赖：第五步风格锚点卡（`templates/style-anchor.md`）④ 色彩体系的主色／辅助色／点缀色 hex，以及 ② 世界美学取向
- 作用：把 S5 定稿的风格卡配色**派生到所有板的外壳**（角色卡／场景卡／道具卡／故事板两版）。版面布局、格位、线宽差异一律保留，只换颜色与艺术字。

> 本文件是「配色来源」的唯一权威。所有板相关文件（SKILL.md S9–S12、asset-design.md、storyboard-style-anchor.md、三份 HTML 卡模板、build_storyboard.py 可选路径）都**引用本文件的变量名**，不写死 hex。具体 hex 在每个项目 S5 定稿后填入风格卡，并由交付/生图流程读取。

## 一、外壳角色 → 风格色映射

| 外壳角色 | 取色 | 说明 |
|---|---|---|
| 图底／卡基（卡片大背景） | 主色浅中性派生 | 主色＋白调到浅 8–15%，非纯白、均匀无渐变无纹理。角色/道具主体也坐在这一色上（见第三节），两者同色无缝 |
| 顶栏带／题材头带／页眉带 | 辅助色浅版 | 辅助色＋白调到浅 15–25%，作为信息带的底色 |
| 分隔线／细框／页脚线 | 点缀色 或 主色深版 | 1px 细线用点缀色；2px 重分隔线（资产卡顶栏）用主色深版 |
| 艺术字标题／正文文字 | 主色深版 | 保证与浅色带、浅色底的对比可读 |
| 故事板题头（深色通栏） | 主色深版实底 | 全页最重的一块，让故事板在文档里立刻与正文分开 |

> 若风格卡未给辅助色，辅助色取主色＋白 30%；未给点缀色，点缀色取主色深版。三者都缺失时退回中性浅灰（仅应急，不应出现在已定稿项目）。

## 二、艺术字规范（由 ② 世界美学取向派生）

| ② 世界美学取向 | 标题字体 | 装饰 | 备注 |
|---|---|---|---|
| 唐风雍容 | 厚重楷书类衬线（颜体风） | 描金细线、对称、略宽字距 | 大气、端正 |
| 宋风清雅 | 纤秀宋体类衬线（瘦金/宋体风） | 留白、细线、紧凑字距 | 文气、克制 |
| 魏晋飘逸 | 行书隶意（半草半隶） | 疏朗、错落、轻笔触 | 潇洒、不规整 |
| 明制端庄 | 规整宋体（官方印刷体风） | 横平竖直、无多余装饰 | 庄重、秩序 |
| 现代（都市写实/生活流） | 无衬线黑体（思源黑体类） | 细分割线、无描边、字距正常 | 越少装饰越可信 |
| 科幻（近未来/硬科幻） | 等宽或无衬线，编号式标注 | 单色标记线、无渐变 | 界面语言优先于装饰 |
| 架空（写参考基底） | 按第六维参考锚点指定 | 随参考锚点 | 不套用上表，直接写字体与装饰 |

> 艺术字只作用于**板的标题与栏目名**（顶栏标题、格标注题、故事板页眉中篇名等），不作用于角色/场景/道具/故事板**画面内的写实内容**（那些服从成片风格，不得被艺术字污染）。

> **② 现在是四轴落成的一句坐标，不是上面这七个选项。** 表按"字体气质"分类，不按题材分类——拿到坐标后先判断它要哪一种气质，再落到表里最近的一行；表里没有的美学自定字体与装饰，判据只有一条：**字体要能读出来源的时代与地域**（年代戏→铅字宋或粗黑＋套色；当代县城→最普通的黑体，不加装饰线；神话志怪→碑刻或写经体），不能用"好看"当理由。架空类直接写字体名与装饰做法，不套用本表。

## 三、风格浅色底（角色/道具展示图专用）

角色卡与道具卡是「展示图」，**风格浅色底**：

- **风格浅色底**：主色＋白调到浅 8–15%，**非纯白**、均匀柔光、无渐变、无纹理、无暗角。
- 仍满足「看清形制」：主体（角色/道具）扣去背景底只留主体，落在风格浅色底上；严禁为填满拉伸变形。
- 配合生图边界（`templates/generation-boundary.md`）：该底必须保持大面积平整安静，不得布满随机微纹理、不得做旧、不得 HDR 烧焦。
- 场景 V01/V02 与故事板六格是成片写实画面，本就不白底，**不套用此条**；它们直接沿用风格卡成片光影。
- **道具卡的「入戏画面」格是唯一例外**：该格要交代道具在实景里被使用或被注视的状态，必须沿用成片光影与场景卡的墙界、陈设、光位，**不回风格浅色底**；同一张卡上，前三格（正／侧／背）仍是浅色底展示图。角色卡五区、道具卡前三格、场景卡六格分工不同，不要为了「整卡统一」把入戏格也刷成浅色底。

## 四、硬约束（改色也不动）

- **序号可读性**：无论底色怎么取色，故事板格左上序号一律「白字＋深色（点缀色或主色深版）描边」，保证任意明暗画面可读。
- **线宽差异保留**：资产卡顶栏 2px 重分隔线（封面级视觉锚点）与故事板页眉 1px 细线（避免与格框抢视觉）的**线宽差异是刻意设计**，改色后依旧保持，不互相「统一」线宽。
- **版面布局零改动**：格位、网格、页眉页脚内容、标注带位置、序号位置、2×3 基准全部不变，只换颜色与字体。
- **全片一致**：同一项目所有板（角色/场景/道具/故事板）共用同一套 palette，不得某板用风格色、某板留黑白灰。

## 五、HTML / CSS 变量名（供三份卡模板引用）

三份 `asset-card-*.html` 在 `:root` 声明以下变量，由项目 S5 定稿后注入具体 hex：

```css
:root{
  --base:        /* 图底/卡基：主色浅派生 */;
  --band:        /* 顶栏/标注/页脚带/说明条：辅助色浅版 */;
  --rule:        /* 细框/格框：点缀色 */;
  --rule-heavy:  /* 资产卡顶栏 2px 重线、深色底栏底色：主色深版 */;
  --ink:         /* 艺术字/正文：主色深版 */;
  --ink2:        /* 次级文字：主色中调 */;
  --tag:         /* 造型/编号色块：辅助色深版 */;
  --num-stroke:  /* 序号描边：点缀色或主色深版 */;
  --art-font:    /* 艺术字 font-family，按第二节 */;
  --label-font:  /* 标签/小标 font-family（无衬线或碑刻感，按第二节） */;
}
```

> 场景卡与道具卡的**底栏**（资产编号条）用 `--rule-heavy` 作底、反白字，是全卡最重的一条线；它不参与「线宽统一」，与顶栏 2px 重线一上一下夹住整卡。每格的**左上角标签**用 `--band` 底＋`--rule` 细框，**格下说明条**同底同框、字号略小一档。

`scripts/build_storyboard.py`（六区段落板与模型版的拼版脚本）同样读取上述变量，不再写死 `#FFFFFF/#F4F4F4/#1A1A1A/#333/#666/#444/#CCCC` 等灰度值。
