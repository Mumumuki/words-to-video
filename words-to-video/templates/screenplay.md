## 一、结构大纲

### 1.1 骨架选型（必读，先选型再填拍）

#### 短片默认骨架：山音四幕式

**只有一个单一核心事件，避免支线。** 短片 / 单段项目直接用这四幕，不必升级到下面的四套方法论：

- **第一幕 · 起因**：开场钩子（前 15 秒的画面/动作）→ 建置（故事常态展现）→ 激励事件（打破平衡）
- **第二幕 · 发展**：冲突升级（障碍 1）→ 冲突进一步升级（障碍 2，**不可省略，且与障碍 1 不同质**）→ 中点（伪胜利/伪失败）与一切尽失
- **第三幕 · 高潮**：最终对决（动作顶点）→ 关键选择与故事反转
- **第四幕 · 结局**：新常态（弧光完成）

> 第二幕的障碍 2 不可省略、且与障碍 1 不同质——只有障碍 1 的故事是"遇到麻烦然后解决"，不是戏剧。时长预算参考：建置约 15%、发展约 40%、高潮约 25%、结局约 20%。

#### 需要更重的骨架时再升级

长内容、多段长篇，或用户明确要求时，再从四套方法论里选（详情见 `references/storycraft.md` 第一节）：

- 商业类型片 / 高概念 → **Save the Cat**（压缩到短片比例）
- 成长 / 冒险 / 变形 → **Story Circle**
- 角色复杂 / 主题先行 → **McKee 价值转变**
- 角色驱动文艺片 → **内在节拍表 + 风格变体**

选型必须在 S3 开场明确告知用户并简述理由；混用也可（如 Story Circle 骨架 + STC 节拍细化）。四幕与四套方法论不是互斥关系——**四幕是容器，方法论是容器内节拍的组织逻辑**。

### 1.2 节拍表

> **戏剧动作 ＝ 目标 ＋ 阻碍。** 每一拍先想清"谁想干什么、被什么挡住"——目标必须有急切性，阻碍必须与目标直接对抗。节拍表本质是"微型戏剧动作"的序列，向上汇聚成全片核心戏剧动作。不成立的拍（目标含糊或没有对手）删掉或合并。

| # | 所属幕 | 节拍 | 本拍改变了什么 | 标注 |
|---|---|---|---|---|
| 1 | 一/二/三/四 |  | 信息/权力/关系/情绪/物理状态/风险 |  |

规则：

- 5–8 拍。少于 5 拍撑不住 1 分钟，多于 8 拍在 1–3 分钟里必然赶。**每拍都要能挂回 1.1 的某一幕**（在表内加一列"所属幕"）。
- **每拍只能改变一项**，写清是哪一项。写不出变化的那一拍，删掉或合并。
- 最后一拍必须是代价或选择，不能只是"她明白了"。
- 每拍都要能挂回核心戏剧动作；原创内容标 `[创作]` 并说明理由。

### 1.3 开场钩子（必交付）

短片前 15 秒定生死，长片／剧集第一场定义全片气质。**开场不是"慢慢进入"，而是"从最有张力的截面切入"**——第一个画面就要让观众产生"怎么回事？"的疑问，同时在交代状态时就制造张力，而非"先交代再开始"。

- 商业／类型片：开场用一场高密度杰出场景，同时亮明角色状态与类型基调。
- 文艺／角色驱动：开场用一段代表全片风格气质的段落，或第一个视觉母题的锚定。
- 安静也可以是钩子：一个"不太对"的日常画面，比爆炸开场更抓人。

**开场自检**：① 第一个画面是否有视觉冲击力或悬念？② 前 30 秒观众是否产生具体疑问？③ 是否在交代状态的同时就在制造张力？④ 类型基调是否与全片一致？⑤ 把开场单独拿出，它本身是否是一段精彩视听内容？

### 1.4 伏笔与回扣登记表（可选，长内容必填）

在结构大纲时填写，跨段 / 跨集也要追踪。规则与登记表见 `references/storycraft.md` 第三节：伏笔首次出现不能太刻意，每个伏笔必须有回扣，回扣要改变观众对前面信息的理解。本表只服务剧本层"种植—回收"一致性，**不增加任何下游字段（不入资产卡六行表、不入故事板 schema）**。

## 二、场景拆解

大纲转成视听单元。每场是一个微型戏剧动作，向上汇聚成全片核心戏剧动作。**每场必须标注预估时长与双轨节奏状态**（山音第六步口径），并在结尾给出时长累计。

### 本场档案

| 项 | 内容 |
|---|---|
| 开场状态 |  |
| **本场改变了什么** | 信息 / 权力 / 关系 / 情绪 / 物理状态 / 风险（只选一项为主，可带一项次） |
| 结束状态 |  |
| 与下一场的因果 |  |

> **本场改变了什么**为空或写"推进剧情"的，视为不合格。这一栏是整份剧本的质检点：一场戏可以不好看，但不能什么都没改变。

### 场次自检（山音第六步）

- [ ] 大纲里每个情节点是否都有具体拆分？
- [ ] 场景连接是否紧凑？相邻场景之间是否有情节过渡？
- [ ] **时长累加是否与目标总时长吻合**？
- [ ] 是否有连续 3 场以上同一节奏状态（情节/情感都是"紧/重"或都是"松/轻"）？有则调整。
- [ ] **情节节奏与情感节奏是否有至少一处错位**（更高级的叙事）？

## 三、场景写作

填充血肉。**这一段的全部纪律可以概括成一句话：只写摄影机能拍到、能听到的东西。**

- 台词承担信息或压力，不承担解释设定。设定交给画面与动作。
- 同一角色全片句式统一：疲惫的人说短句，紧张的人重复，撒谎的人解释过多。
- 不写总结式发言（"我们之间的关系……"）。人物不会给自己的处境下定义。
- 台词与动作冲突时以动作为准：说"我没事"同时手在抖，比任何台词都有效。
- **禁心理描写（红线）**：不写"他觉得""她意识到""内心涌起"之类。只写摄影机能拍到的动作与能听到的声音；一个情感若无法用角色的物理行为传达，就不应出现在剧本里。
- **潜台词（冰山）**：角色说出来的只是表面，真意在水下。避免 on-the-nose 直白对白，用动作、停顿、回避、话题转移表达。删掉所有台词后，观众仍大致懂发生了什么。
- **防 AI 腔**：不写过度比喻、类比与书面化台词；不同角色用不同说话方式（用词、句式长度、习惯表达）。对话自然传递信息，不让角色说出双方都已知道的事。

### 双轨节奏（可选工具）

节奏有两条可错位的轨道，错位本身就是叙事力：

- **外部情节节奏**：事件密度与强度（紧／中／松）。
- **内在情感节奏**：角色情感波动（重／中／轻）。

错位范例：情节松＋情感重（两人安静吃饭，但观众知其一明日将走）；情节紧＋情感轻（追车戏配轻松流行乐）。**避免两线长时间同高（疲劳）或同低（无聊），任一单调上升无回落（无呼吸）。** 可在本场档案后附一句"本场情节／情感＝？"辅助排段落。

## 五、剧本医生（S3 自检 / 抛光）

S3 产出后、进第四步前，以剧本医生身份通读全片做诊断（维度见 `references/storycraft.md` **第六节**；清单与输出前自检见**第八节**）：价值转变、鸿沟递进、危机选择、无效情节、伏笔审计、群像审计、节奏诊断、开场质量。

输出格式（山音第八步）：

```
* 诊断报告：
  * 节奏问题：（含双轨节奏诊断——情节与情感的起伏是否合理？）
  * 时长问题：（哪些场过长/过短？高潮段时长是否足够？）
  * 逻辑漏洞：
  * 对话问题：

* 优化建议：
  * [建议 1：针对某场的潜台词重写]
  * [建议 2：针对结局的反套路构思]

* 综合自检：按四大板块（核心概念 / 人物 / 结构 / 视听）给最终评语及修改意见
```

> 剧本医生只动剧本层，不新增资产设定——需要新增人物 / 造型 / 道具时回退第二步或第四步，不在此处就地造设定。
