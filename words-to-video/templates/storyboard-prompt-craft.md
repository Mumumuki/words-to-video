# 第十二步 a 段｜关键帧画面提示词打磨

- 项目：
- 版本：SB-PROMPT-v1
- 位置：第十二步的前半段——资产图已齐、故事板尚未出图
- 上游：G3（`分镜定稿`）已展示并定稿的分镜表与六段式、第九至十一步已生成并通过复核的资产图
- 下游：第十二步 b 段出图与排版 → c 段出图自检 → 第十三步交付文档

> 本段不新增步骤、不新增确认口令，只是第十二步内部的第一个动作。

## 一、这一步在链路里的位置

第七步定下了「拍什么、怎么动」，第八步把它写成提示词，第九至十一步把角色、道具、场景变成了真实的图。到这里，画面第一次有条件被真正描述清楚——因为参考图终于存在了。

所以第十二步的前半段做一件事：**把已确认的分镜语言，翻译成能直接喂给生图工具的关键帧画面，并让六格服从同一套镜头语言纪律。** 它不重新决策：分镜里没定的情节、没登记的造型、没判定的道具，一律不在这里出现。翻译完成后才进入 b 段出图。

```
S7 分镜表（拍什么、怎么动）
  → S8 提示词包（文字确认）
  → S9–S11 资产图（真实的形）
  → 【本段】关键帧画面提示词打磨（分镜语言 → 生图语言，服从镜头纪律）
  → S12-b 逐帧生图 + 本地排版
  → S12-c 出图自检
```

## 二、镜头语言纪律（每帧写完过一遍）

写这 N 格时，下面九条是硬约束，不是风格建议。

1. **新信息原则**：每一格必须比上一格多给出一样东西——新主体、新动作、新情绪或新空间。N 格里出现两格「构图相同、只是人物位置略动」，等于浪费一格；补帧规则里「禁止复制同一构图」正是这条的延伸。
2. **景别用封闭八级，不自造**：大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写。禁止写「中景偏近」「半身偏上」这类含糊词；确实介于两级之间时，写靠哪一级并说明理由。
3. **角度枚举**：平视 / 仰拍 / 俯拍 / 顶拍 / 荷兰角 / 过肩 / 主观 POV / 镜像。角度必须服务情绪，不能为了好看随手选。
4. **运镜枚举**：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 环绕 / 手持 / 变焦。组合运镜拆解标注（如「摇 + 推」），并一律写成「起幅 → 运动方式与速度 → 落幅」。固定镜也要写明起幅与落幅构图不变。
5. **转场枚举**：硬切 / 叠化 / 淡入 / 淡出 / 划像 / 匹配剪辑 / J-cut / L-cut / 黑场。默认硬切；非硬切必须有叙事理由（时间流逝、情绪收束、声画先行等）。
6. **30 度规则**：同一主体、同一景别的相邻两格，机位夹角至少 30°。否则两格看起来像同一张图，观众读到的是「画面卡住」而不是「时间推进」。
7. **轴线与视线匹配**：先定本段轴线基准（双人位置关系或运动方向），180° 内设机位。A 看画左，被看者必须在画右或从画右入画。确有越轴需求时，必须写清补偿手段（动作引导越轴 / 中性方向镜头 / 双主体同时运动）。
8. **大运镜要有内部层次**：起幅（入画状态）→ 调度（谁或什么在变、机位怎么跟）→ 落幅（出画或定格）。只写「镜头推近」没有调度层，画面会停在半路不知道落在哪。补出的工序帧正应该承载这一层。
9. **只写可拍、可录的**：画面描述四要素为**主体 / 动作 / 构图 / 光线**。禁止写心理与抽象（「他感到孤寂」「气氛压抑」）——要写成画框内看得见的东西（「人物独坐、视线落在地面那片冷白光斑上，肩线松垂」）。

## 三、先定情绪，再定镜头

选景别前先问：这一格要观众感受到什么。按下表落到镜头，再写画面。

| 情绪 | 景别 | 角度 / 运镜 | 节奏 | 常见落点（示例，按题材替换） |
|---|---|---|---|---|
| 孤独 / 渺小 | 大远景 / 远景 | 固定 | 长 | 羁旅、望乡、独坐、江天一色 |
| 压迫 / 威慑 | 全景以下 + 广角 | 仰拍、缓推 | 慢 | 宫阙、军阵、权势对峙 |
| 紧张 / 惊恐 | 特写 / 大特写 | 手持、荷兰角 | 快切 | 惊变、夜行、闻讯 |
| 暧昧 / 亲密 | 近景 / 中近景 | 浅焦、缓推 | 慢 | 闺情、对饮、别前低语 |
| 怅惘 / 追忆 | 中景 → 缓拉 | 平视、固定或极缓拉 | 慢 | 怀旧、物是人非 |
| 混乱 / 失控 | 多景别乱序 | 手持、急摇 | 极快 | 战乱、奔逃、狂喜 |

> 情绪来自本段在故事里的功能，不是来自画面好不好看。同一段内情绪未变时，景别与运镜应**渐进演化**，不要每格重置镜头语言。
>
> **最后一列只是举例，且例子偏古典向。** 同一情绪换题材只换取景载体，不换镜头逻辑——"孤独"在当代是末班车的空站台，在年代戏是厂区夜班的路灯，在科幻是舱内一人值守；景别、角度、节奏仍是同一行。

## 四、光影与色调措辞库

写光影时从这里取词，保证全片措辞一致（仍以第五步定稿风格卡为唯一基准，本表只提供词汇）。

**打光**：伦勃朗光（立体、深沉，人物内心戏）／蝴蝶光（精致，女性特写）／剪影与逆光（神秘、疏离，抉择与登场）／顶光（压迫、审判）／底光（恐怖、失常）／窗光（温柔、真实，日常戏）／烛火光（私密、暖橙点缀）／月夜冷光（静谧、清寒）。

**色调-情绪**：暖黄＝温馨、怀旧／冷蓝＝疏离、悬疑／青橙对比＝冲突、大片感／低饱和＝压抑、文艺／高饱和＝活力、喜剧／黑白＝回忆、风格化。

**纪律**：打光与色调写进每一格，不是只在段首写一次。同一段内光源方向、色温、明暗比必须保持连续；要变，必须有叙事理由（灯灭、云遮月、日出）。

## 五、生图提示词公式（紧凑版）

b 段实际生图时用这条紧凑骨架，一段话说完，不套字段：

```
[风格词] + [画幅] + [景别与等效焦段] + [主体与动作] + [构图] + [光线] + [色调] + [镜头级约束]
```

示例：

```
低饱和电影写实，轻胶片颗粒，16:9，中景 50mm 平视略带 5° 俯角，唐代男子着靛青粗麻中单与麻布袴、
布袜，自矮榻撑坐起身，右手撑榻沿，位于画面左三分线，右侧留出直棂窗与地面月光光斑，
窗外满月自右后方斜射的冷白逆光、右侧轮廓一道边缘光、左脸留在暗部，冷灰环境配深褐暗部，
只给侧脸不露正脸、不得出现第二人。
```

**负面词基线**：`文字、水印、多余肢体、构图错乱、赤身露体、无裤`，并叠加项目统一负面词与风格卡禁止项（写实加「插画感、3D 渲染感」），以及生图边界 DO/AVOID（见 `templates/generation-boundary.md`，全段拼接）。

## 六、打磨四步

1. **定情绪**：本格在段内承担什么情绪，查第三节表，落到景别、角度、运镜。
2. **定镜头**：按第二节九条纪律过一遍，尤其是新信息、30 度、轴线视线。
3. **填公式**：按第五节公式写出紧凑生图提示词，确认参考图（角色造型图、场景视角图）已指定。
4. **留详尽版**：把同一帧的详尽内容（含时间递进、表演调度、声音、衔接）交给第八步；第八步按**镜头**写成 H3 六段式的 `[Shot N]`（`templates/h3-six-part.md`），带时间码与硬切/承接标记。此处打磨的每格内容，是六段式里对应时间段的画面依据——**格是画面锚点，Shot 是镜头单位，两者数量可以不等（镜头数 ≤ 本段格数 N，每镜至少占一格）**。

> 紧凑版与详尽版写的是同一帧，不是两份内容：紧凑版喂给生图工具，详尽版进第八步六段式里对应时间段的 `[Shot N]`。两者在人物、动作、构图、光线、运镜上必须完全对齐，出现分歧以第七步已确认分镜表为准。

## 七、禁止

- 不在这里新增情节、人物、造型或道具；需要时回退第七步或第四步。
- 不为了画面好看更改已确认的景别、机位、运镜与关键帧结构。
- 不用空泛形容词（很电影感、构图优美、光影绝美）替代具体决策。
- 不把资产图未覆盖的内容写成「已参考」；缺图时按「缺失待补」处理。
