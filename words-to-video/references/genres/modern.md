# 现代题材包

> 作用域：题材轴①落在**当代**（当代都市／县城／乡村／边地／海外）时按需加载；轴②不限定——都市、职场、家庭、现实向悬疑都适用。
> 本文件只补"现代独有的世界规则、视觉词汇与常见错误"，不改变主流程任何步骤与门禁。
> 不加载 `char-library/historical/`（古典形制＋architecture＋objects）——那三份是**历史形制考据**专用。

## 一、最容易失败的地方

现代题材看起来最好写，其实最容易假。四个高频失败：

1. **伪职场**：角色头衔很高，但从不做具体工作。没有人打开电脑、填表、接电话、签字、被上级驳回。
2. **空镜堆砌**：用城市夜景、车流、咖啡杯代替叙事。镜头很漂亮，但这一幕没发生任何事。
3. **所有人一个腔调**：不同年龄、职业、阶层的人用同一套句式和词汇。
4. **社会关系失真**：该有手续的地方没有手续，该有旁观者的地方空无一人。

## 二、世界规则：现代的特有约束

写进 `canon-bible.md` 第一章时参考：

| 类别 | 可用的真实约束 |
|---|---|
| 制度 | 报警要出警时间；医院有分诊与陪护规定；公司流程要走审批 |
| 技术 | 手机有电、有信号、有锁屏；监控有死角也有覆盖；定位可被关掉但有痕迹 |
| 经济 | 房租、工资、通勤时间决定一个人能去哪里、能待多久 |
| 社会 | 门禁、保安、邻里、同事的注视——现代人很少真正独处 |
| 时间 | 末班车、营业时间、排班表是最便宜的压力来源 |

**现代戏的紧张感通常来自"被人看见"，不是"没人看见"。** 这条比任何视觉参考都有用。

## 三、语言与对白

- 台词里不出现"我们之间的关系需要重新定义"这类总结式发言，人不会这样说话。
- 职业术语要具体到岗位：护士说"补液"，不说"治疗"；程序员说"回滚"，不说"修复系统"。
- 不同人说话长度不同：疲惫的人说短句，紧张的人重复，撒谎的人解释过多。
- 方言、口音、网络用语可作身份标记，但一个角色只用一两个，不要全上。

## 四、视觉词汇

写风格卡与资产提示词时可用：

- **光源**：办公区冷白顶灯、便利店冷白＋暖黄招牌、手机屏幕光、电梯轿厢顶灯、地下车库钠灯、路灯的橘黄光斑
- **空间**：玻璃隔断、消防通道、电梯、地下车库、便利店、出租屋、老旧居民楼楼道、天桥、24 小时自助银行
- **材质**：瓷砖、水磨石、喷涂金属、亚克力、磨砂玻璃、防水漆、地胶
- **影像质感**：手机竖拍的手持抖动与过曝、监控画面的低帧率与边缘畸变、行车记录仪视角

## 五、检查清单

- [ ] 主要角色有具体职业与具体动作，能被拍出来
- [ ] 每场都发生了信息、权力、关系、情绪、物理状态或风险上的变化
- [ ] 台词没有总结式发言，不同角色句式有差异
- [ ] 世界规则里至少有一条是"制度性约束"（手续、权限、时间），且真的挡过人物一次
- [ ] 没有用空镜代替叙事
- [ ] 没有出现需要授权却毫无障碍的场所（警局、医院、机房、住宅楼层）
