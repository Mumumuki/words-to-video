# 题材定位与发散（总纲）

> 本文件回答两个问题：**这个项目是什么题材**、**还能是什么题材**。
> 它不替代任何题材包，是全库题材判断的入口。`classical.md`／`modern.md`／`scifi.md` 是三个常见落点的**深水包**，不是题材全集。

## 一、为什么不给固定清单

题材不是三个抽屉。同样写"一个人守着一件没人要的东西"：

- 放在宋代夜巷，是志怪边缘的克制；
- 放在 1990 年代东北厂区，是下岗年代的挽歌；
- 放在近未来的轨道城，是硬科幻的冷；
- 放在当代县城早餐摊，是生活流的暖。

**故事内核可以一样，题材换的是"这件事发生在什么物理与社会环境里"。** 环境决定光源、器物、语言、社会关系、人物能做什么不能做什么——这些才是题材真正管的东西。所以题材不该是一道选择题，而是一组坐标。

## 二、四轴定位法

题材由四个正交轴共同确定。每轴给一个值，四轴一组就是这个项目的题材。

### 轴① 时代与世界（决定：器物、服饰、建筑、技术可用性、光源合法性）

| 段位 | 取值举例（开放集，可自造） |
|---|---|
| 远古 | 史前、上古神话、巫傩、部落 |
| 历史 | 先秦、汉、魏晋、唐、宋、元、明、清（细分到朝代） |
| 近现代 | 清末民初、民国、战时、1950s、1960s、1970s、1980s、1990s |
| 当代 | 当代都市、当代县城、当代乡村、当代边地、当代海外 |
| 未来 | 近未来（10–50 年）、远未来、后文明、星际 |
| 架空 | 东方幻想、中世纪风、蒸汽朋克、柴油朋克、赛博、太阳朋克、生物朋克、废土 |
| 非现实 | 神话世界、志怪世界、梦境、意识内、非欧空间 |

### 轴② 类型片（决定：节拍、悬念机制、情绪曲线）

悬疑／犯罪／黑色电影／恐怖（心理·民俗·身体·宇宙）／爱情／家庭／成长／职场行业／程序剧／战争／灾难／生存／武侠／动作／追逐／公路／漂泊／喜剧（荒诞·黑色幽默·冷面）／纪实／伪纪录／散文电影／寓言／实验／诗电影

> 类型片与来源形态无关。改编一首古诗，也可以拍成程序剧式的"一件事按规矩办完"。

### 轴③ 地域与文化质感（决定：语言、器物、光色、社会关系密度）

中国（东北／华北／江南／西南山地／西北／岭南／闽台／藏疆）／东亚（日／韩／东南亚）／南亚／中亚／中东／欧洲（北欧／南欧／东欧／英伦）／非洲／拉美／北美／极地／海岛／沙漠／高原

### 轴④ 调性（决定：风格卡六维的具体数值）

克制←→浓烈　写实←→风格化　明亮←→阴郁　日常←→奇观　冷←→暖　慢←→快

### 用法

`project-brief.md` 的"题材"字段写成一行四轴定位，例：

```
时代世界：1990s 东北厂区 ／ 类型片：成长＋家庭 ／ 地域：中国东北 ／ 调性：克制·写实·冷
```

四轴全部写出来之后，题材包的加载就有依据了：**只有轴①落在"历史"或"架空中的历史向"时才考虑古典考据**；轴③决定地域质感词；轴④直接进风格卡第④⑤维。

## 三、发散怎么做

用户给了一句话、给了具体题材、或者什么都不给时，按这三个方向发散：

**1. 保留故事，换环境。** 把同一句话放进不同轴①，看哪一版的约束最能把人物逼到墙角。一句话通常经得起换三四个时代。

**2. 换类型片，不换故事。** 同一件事，当悬疑拍是"谁干的"，当程序剧拍是"手续怎么办完"，当散文电影拍是"这件事如何被记住"。**类型片换了，节拍表整张要重写**——这是最有产出量的发散方向。

**3. 反向配轴。** 刻意选一个不常见的组合，往往比"标准配法"好看：

| 反常规组合 | 会得到什么 |
|---|---|
| 清代／民俗恐怖／江南 | 考据是真的，恐惧来自规矩而不是鬼 |
| 当代／武侠／写字楼 | 招式变成话术与汇报，兵器变成流程 |
| 近未来／家庭／县城 | 高科技只作为背景故障出现，人物还在为彩礼吵架 |
| 神话／程序剧／天庭 | 神仙也有排班表，救人的审批卡在第三道 |
| 1990s／犯罪／东北 | 冷、空、大厂房，人比案件更重 |
| 民国／黑色电影／上海 | 雨、霓虹、楼梯间，真相换不来钱 |
| 上古／诗电影／西北 | 几乎没有对白，全靠地貌与火 |

> 发散的目的不是猎奇。**一个好题材会让原来的故事变得更难写、但也更值得写**；如果换了题材之后故事变得更容易了，多半是换成了更套路的版本。

## 四、量力约束（发散之后必须收）

短片不是长片。**题材只是质感，不是设定集。**

一个 60 秒项目只有四处真正花得掉题材的成本：

| 落点 | 上限 | 超出会怎样 |
|---|---|---|
| S2 世界规则 | 最多 4 条 | 第 5 条以后一定没有镜头承载，只是纸上的设定 |
| S4 场景卡 | 1 张 6:5，6 个格位 | 想展示整座城市的结构，最后只画出 6 个格子 |
| S4 角色／道具卡 | 按判定，宁少不多 | 世界观全靠加角色来撑，成本翻倍而信息不增 |
| S5 风格卡六维 | 六维各一句 | 题材的"味道"最终只能靠这六句落地 |

**判定方法：一条题材设定如果说不清"它落在哪个镜头或哪张卡上"，就删掉。**

题材发散的程度和时长强相关：

| 时长 | 题材能承载到什么程度 |
|---|---|
| 10–30 秒 | 只有质感：一个光、一个物件、一个动作。世界规则 1–2 条 |
| 45–90 秒 | 质感＋一条规矩：规矩被违反一次。世界规则 3–4 条 |
| 2–3 分钟 | 可以有一个小社会的横截面，但仍只取一个事件 |
| 3 分钟以上 | 才谈得上"世界观"，且仍建议单场景单事件 |

## 五、与内容类型的关系（不要混）

| | 是什么 | 取值 |
|---|---|---|
| **题材** | 这件事发生在什么环境里 | 四轴定位，**开放**，可自造 |
| **内容类型** | 这部片子靠什么推进 | `剧情演绎`／`MV`，**只有两种** |
| **来源形态**（仅登记，非流程路由） | 有没有原作可忠 | `adaptation`／`original`／`hybrid` |

三者互相独立。任何一个题材都可以走剧情演绎或 MV；任何一种来源形态都可以落在任何一个题材上。**不要因为题材陌生就改走 MV，也不要因为题材宏大就放宽内容类型的判定。**

## 六、自检

- [ ] 四轴都写了值，没有一轴空着（空着的轴会在后面变成"看情况"，而"看情况"最后就是没定）
- [ ] 题材的每个特征都能指到一个镜头或一张卡，指不到的不写进设定
- [ ] 世界规则条数没超过时长对应的上限
- [ ] 地方性／年代感不是靠滤镜，而是靠**具体器物与社会关系**（一件会响的东西、一个必须办的手续）
- [ ] 没有把"古风""赛博感""氛围感"这类词当作题材定稿——它们不是风格卡，风格卡必须六维写完
- [ ] 换过至少一个方向做对照（换时代或换类型片），确认当前这一版确实更好
