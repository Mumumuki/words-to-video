# 古典题材包（索引）

> 作用域：题材轴①落在**历史**（先秦至清）或**历史向架空**（东方幻想、仙侠、古风）时按需加载。
> 本文件**不复制**考据内容，只做三件事：指向既有考据文件、说明哪些字段只在此题材加载、补古典叙事与视觉的检查项。
> 既有考据文件的正文保持原样，不改写。

## 一、加载哪些文件

| 文件 | 何时加载 | 用途 |
|---|---|---|
| `references/char-library/historical/古典形制.md` | 涉及服饰、发式、冠履、妆容时 | 形制与层次的 `[推断]` 参考 |
| `references/char-library/historical/architecture.md` | 涉及建筑、院落、陈设、空间结构时 | 空间与构造的 `[推断]` 参考 |
| `references/char-library/historical/objects.md` | 涉及器物、文房、食器、兵器时 | 器物形制与材质的 `[推断]` 参考 |

三份文件都只是**提示来源，不是唯一答案**。写入设定与提示词时仍需标 `[推断]`，不得因为"参考文件里有"就升级为 `[来源]`。

**不涉及历史形制考据的项目（当代、未来、架空非历史向）一律不加载这三个文件。** 它们的形制规则会直接把画面拽回古代。

> 本包不是"古典题材"的代名词，而是"**需要历史考据的题材**"的深水包。民国以后的年代戏、历史向架空都不在本包作用域内，但可借用第三、四节的检查项（光源可解释、动作受衣着限制、不用标签代替风格卡）。

## 二、只在古典项目生效的字段

以下字段在 `asset-design.md` 与 `style-anchor.md` 中标注为"古典适用"：

- 服饰的**形制／层次**（外层、内层、足服、束带的分层写法）
- 建筑的**院落层次与朝向**（几进、坐北朝南、影壁位置）
- 器物的**朝代特征与工艺痕迹**
- 风格卡六维中的**世界美学取向**：历史向题材落成具体朝代与地域的美学坐标（如"宋·江南市井·素朴不做金饰"），**不写"古风"**

## 三、古典叙事检查

- [ ] 台词的文白程度全片统一：不要旁白文言、对白白话、字幕又半文半白
- [ ] 称谓与身份匹配（自称、他称、上下关系），不出现现代称谓混入
- [ ] 时间表达用故事内可理解的词（更、时辰、日头），不用"三点钟"
- [ ] 不具备现代便利：无电、无即时通讯、夜间行动受灯火与城门限制
- [ ] 动作符合衣着限制：长袍、宽袖、冠帽会限制跑、跃、低头

## 四、古典视觉检查

- [ ] 光源可解释：烛、灯、窗、月、天光；不出现无来源的均匀打光
- [ ] 器物尺度真实：案、几、榻、屏风与人体比例正确
- [ ] 材质不过度做旧：不要用满屏裂纹、污渍当"历史感"
- [ ] 服饰层次写全：**只写外袍会导致下身赤裸**，必须写明内层下装与足服（见 SKILL.md 生图执行要点第 1 条）
- [ ] 不把"古风"当风格：风格卡仍需六维定稿，不用"古风"两个字替代

## 五、常见失败

1. **考据代替戏剧**：把大量形制信息塞进画面，但这一场没有发生任何事。
2. **影楼感**：服饰崭新、光线均匀、人物摆拍，像写真而不是叙事。
3. **朝代混搭**：唐代服饰配明清家具，且没有任何说明。混搭可以，但必须是自觉的世界设定，不是疏忽。
4. **文言堆砌**：为了"古意"写观众听不懂的台词。听不懂的台词等于没有台词。
