# 器物与道具速查（仅作推断提示）

> **作用域：需要历史形制考据的项目**——古典、古装、历史剧、历史向架空。当代与未来项目不加载本文件（器物形制与工艺痕迹按古代断代组织，套用会直接穿帮）；民国以后的年代戏只在核对器物尺度时参考。

> 用法：仅作 `[推断]` 提示，不替代断代。先检查原文是否明确写出器物，再考虑材质、用途、持有者与使用痕迹。

| 类别 | 关键特征提示 | 常见错误 |
|---|---|---|
| 文房 | 笔、墨、纸、砚可按原文和写作行为设置；具体形制、纸张与装订方式须按时期判断 | 任意出现线装书、现代宣纸包装、钢笔式握笔或印刷字体 |
| 饮食 | 陶、瓷、漆、铜、银等材质须结合时期、身份和用途；分清杯、盏、碗、壶 | 所有时代都用同一套白瓷茶具；把现代泡茶方式直接前移 |
| 灯具 | 可区分烛、油灯、灯笼等光源，具体燃料、形制与光色须推断标注 | 出现电灯式照明；无烟火、无灯油的全新道具；亮度超过光源能力 |
| 兵器/马具 | 先明确用途、时代、身份与佩戴方式，再描述铁、铜、木、革等材质 | 游戏化夸张比例；跨时代混搭刀制、鞍具和甲片 |
| 日常器物 | 箱笼、镜、扇、伞、车舆等须核对出现时期和使用场景 | 把现代物件改做旧就称古代；尺寸与人物动作不匹配 |

通用填写：名称＋具体材质＋大致尺寸＋纹样（无依据则省略或标创作）＋使用痕迹＋时代/身份依据。禁止编造出土文物编号或“某馆藏品同款”。
