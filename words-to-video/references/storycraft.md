# 剧本打磨工艺库（S0–S3 内部用，不展示给用户）

> **定位**：本文件是编剧 Agent 在「项目定义 → 设定 → 故事与剧本」阶段（S0–S3）的内部工艺库，承接 `references/ideation-toolkit.md`（负责"想出什么故事"），本文件负责"把故事打磨成超级剧本"。
> 所有内容默认服务于**短片 / 单句话原创**；标注「长内容可选」的模块仅在项目扩展到长片、剧集或多段长篇时启用。
> **硬边界**：本文件只影响 S0–S3 的剧本层与设定层。所有产出的"深度字段"（Ghost/Lie/Flaw/矛盾性、伏笔、群像功能等）**不进入第四步资产卡六行信息表，也不进入第十二步故事板 schema**——故事板与资产卡的结构由各自模板独立锁定。

---

## 一、骨架方法论选型

S3 的"节拍表 / 场次表"是局部骨架；下面四套方法论是**骨架选型**——决定整片用什么逻辑组织。先用本表选定一法，再让 S3 节拍表去实现它。

> **短片 / 单段项目的默认骨架是山音四幕式**（起因 → 发展 → 高潮 → 结局，见 `templates/screenplay.md` 1.1），**不需要在本表选型**。本表的四套方法论在长内容、多段长篇、或用户明确要求更重的骨架时才启用——四幕是容器，方法论是容器内节拍的组织逻辑，两者不互斥。

| 题材 / 意图 | 推荐方法论 | 原因 |
|---|---|---|
| 商业类型片（动作、惊悚、喜剧、恐怖）、高概念 | **Save the Cat 15 节拍**（压缩版） | 节拍精确到比例，强情节驱动 |
| 成长 / 冒险 / 变形记、主角内外旅程同步 | **Story Circle** | 八步圆环天然适合"离家→历险→回归" |
| 角色复杂、主题先行、需要深度戏剧 | **McKee 价值转变** | 以价值翻转与鸿沟为核心，杜绝废场景 |
| 角色驱动型文艺片、作者气质 | **内在节拍表 + 风格变体** | 节拍是内心状态转变而非外部事件 |

> 选不出来时默认用 **Story Circle** 做骨架，再用 S3 节拍表细化；也可混用（如 Story Circle 骨架 + STC 节拍细化）。**选型要在 S3 开场明确告知用户并简述理由**；用户未回应即按推荐项继续展开，**不中断流程去等一句通过口令**（G1 是检查点）。

### 模板 A：Save the Cat（压缩到短片比例）

短内容不必用满 15 拍，抓关键骨架：开场画面 → 主题陈述（旁人一句点题）→ 建置 → 催化剂（激励事件）→ 犹豫 → 进入新世界 → B 故事（关系线）→ 游戏时间（主角试错）→ 中点（伪胜/伪败，赌注升级）→ 敌人逼近 → 一切尽失 → 至暗时刻（直面 Lie/Ghost）→ 第三幕转折 → 高潮（五步：集结→执行→计划失败→挖掘内心→新计划）→ 终场画面（与开场对照的新常态）。

### 模板 B：Story Circle（八步）

YOU（舒适区常态）→ NEED（产生欲望）→ GO（跨过阈值）→ SEARCH（试错挣扎）→ FIND（得到想要的，带代价）→ TAKE（付出代价，最远离起点）→ RETURN（回到熟悉处境但已变）→ CHANGE（新常态）。前四步与后四步互为镜像，天然有"完成感"。

### 模板 C：McKee 价值转变

每个场景都必须让某个人生价值（爱/恨、自由/束缚、真相/谎言、生/死…）发生不可逆的正负翻转；没翻转的场景删掉。**鸿沟（The Gap）**：角色预期结果与实际结果的落差，落差层层加深即张力递进。**控制性理念**：用"价值 + 原因"一句话表达的主题判断（如"正义获胜，因为主角愿牺牲所珍视的一切"），它决定结局。

### 模板 D：内在节拍表 + 风格变体（文艺片）

六步内在节拍：常态与裂缝 → 扰动 → 游走与回避 → 对峙 → 选择或接受 → 余震（开放）。按审美选变体：是枝裕和（日常流）、王家卫（情绪流/旁白错位）、小津（静物流/枕镜头）、Linklater（对话流）、奉俊昊（类型杂交/空间即隐喻）。变体只改"质感"（停留多久、留白比例），不换六步骨架。

### 与 S3 节拍表的映射

- 短片 / 单句话原创：直接产出 S3 的 **5–8 拍节拍表**，每拍对应上述某个骨架节点；仍遵守"每拍只改变一项、末拍必须是代价或选择"。
- 长内容可选：骨架先按 STC / Story Circle 拉通全片，再下钻到 S3 节拍表与场次表；此时节拍表可超过 8 拍，按段落（P）切分。

## 二、主题论点 / 控制性理念（McKee）

长内容或主题先行的项目，S2/S3 阶段要明确一句话**控制性理念**：`[价值] + [原因]`。它不等于"关于勇气"这种模糊词，而是一句可论证的判断。例："爱情在功利面前溃败，因为算计终将腐蚀真诚。" 它决定结局——结局就是这句话的证实或证伪。**短内容可略，但一句话原创若想有"超级剧本"的厚度，建议补一句。**

## 三、伏笔与回扣系统

在 S3 结构大纲时填写下表，长内容跨段/跨集也要追踪。规则：伏笔首次出现不能太刻意（观众不应意识到"这是伏笔"）；每个伏笔都必须有回扣；回扣要改变观众对前面信息的理解；至少 3–5 对分布在不同层次。

```
伏笔内容 | 层次（道具/台词/行为/结构） | 首次出现位置（场次/段落） | 回扣位置 | 回扣方式（如何改变含义）
---------|--------------------------|------------------------|---------|------------------------
```

层次示例：道具伏笔（日常物变关键道具）、台词伏笔（闲聊句后获新义）、行为伏笔（习惯动作暗示 Ghost）、结构伏笔（看似无关场景后证关键）。**登记本身不增加任何下游字段**，只服务于剧本层的"种植—回收"一致性。

## 四、次要角色功能分类 + B Story 映射

每个有台词的次要角色至少承担一个功能（最好两个），无功能的合并或删除：

- **镜像角色**：走主角没走的路——"如果主角做了不同选择，就会变成这个人"。
- **催化角色**：推动主角变化的外力（导师、诱惑者、挑战者）。
- **主题角色**：具象化主题论点的某个立场（B Story 角色通常是这个）。
- **节奏角色**：喜剧 relief / 情绪调剂，给紧张段落一个喘气点。

B Story（关系线）承载主题论点：A Plot 问"主角能否达成目标"，B Plot 问"主角能否成长"；两线在"中点"交汇。次要角色台词风格必须与主角可分辨（遮住名字也知是谁在说话）。**群像片额外要求**：关系矩阵 + 视角切换规则 + 所有人 want/need 指向同一主题。

> 这些功能标注写进 `templates/canon-bible.md` 的人物表（可选列），**不进入第四步资产卡六行信息表**。

## 五、暗线设计（长内容可选）

暗线是不在前台的故事线——首次观看注意不到，二刷才发现"从一开始就铺了"。方法：先定暗线终点（浮出时要揭示什么）→ 反向推导需要埋多少暗示 → 每个暗示都有"表面含义"（一刷读表面，二刷读暗线）→ 浮出时机通常在高潮/结局。长内容 1–2 条即可，太多会过载。

## 六、剧本医生诊断维度（S3 自检 / 抛光，也用于 G1 前通读）

作为剧本医生通读全片时，逐维度诊断：

1. **价值转变**：每个场景结束时核心价值是否与开始时不同？没变的考虑删掉（McKee）。
2. **鸿沟递进**：角色的预期与结果落差是否层层加深？同一难度的困境重复出现＝故事停滞。
3. **危机选择**：高潮是否是一个真正的两难（两害相权 / 两善相权），而非明显偏向一方？
4. **无效情节**：有没有"只推进剧情"却什么都没改变的场？对照 S3「本场改变了什么」。
5. **伏笔审计**：逐条检查伏笔登记表——每个伏笔是否都有回扣？埋了忘回扣＝烂尾。
6. **群像审计**：每个有台词的角色是否都有功能？是否只是"给主角递个信息就消失"的工具人？
7. **节奏诊断**：用场景时长汇总 + 双轨节奏图检查——高潮段时长是否够？建置是否太长？是否有连续 3 场以上同节奏？两个高情感场景间是否有呼吸？情节/情感两线是否长时间同高（疲劳）或同低（无聊）？
8. **开场质量**：把开场单独拎出，它是否是全片最精心设计的段落之一？（见 screenplay.md 开场钩子自检）
9. **常见陷阱对照**：第二幕松垮 / 弧光太线性（缺伪变化）/ B Story 脱节 / 高潮只是"更大的打斗" / 世界观一次倾倒 / 伏笔太刻意 / 群像工具人 / 节奏单调 / 没有时长预算导致高潮被压缩。

输出格式：`诊断报告（节奏问题 / 时长问题 / 逻辑漏洞 / 对话问题）` + `优化建议（潜台词重写 / 反套路构思 / 某场补拍）`，最后给综合评语。

## 七、视听思维武器库（构思 / 剧本层思维，导演阶段具体化）

> **边界声明**：本节的"视听手法"是**剧本层的思维工具与意图标记**，用于决定"这场戏用什么视听逻辑成立"。它**不进入第十二步故事板 schema、不替导演阶段做镜头决策**——故事板的结构（grid_of、两版式、crop 坐标）由各自模板独立锁定。这里只帮 S3 在剧本里埋下"纯视觉建立""零解释"的意图，导演阶段再具体化。

**纯视觉建立原则（任何格式通用）**：不解释规则，直接用画面展示后果；能用 5 秒画面讲清的，不用一句对白。这是"概念纯度"的底层——你的 logline 如果一句话说不清、5 秒画面呈现不了，说明核心概念还不够锐利（回头用 ideation-toolkit 重磨）。

**跨格式视听手法（标记意图，导演具体化）**：分屏（对比/并置）、跳切蒙太奇（时间压缩/重复荒诞）、交叉剪辑（张力累积）、倒放（结果先于原因）、定格（强制注意翻转瞬间）、对称构图（秩序/压迫）、画面内前景/背景叙事（无剪辑并置）、色彩限制（颜色即叙事）、画面与声音错位（讽刺）、环境音放大（日常变不安）、静默（高密度后的真空）、一镜到底 / 固定机位时间流逝 / 连续推轨（变与不变对比）、屏幕录制 / 伪文档（当代感/以真壳包荒诞）、数据可视化（冷静数字衬悲剧）。

**使用原则**：一部片子聚焦 1–2 种核心手法用到极致，不堆砌；手法需递进（升级/变异/结尾被打破）；手法可成为翻转工具（最后 1 秒加速、全片彩色终变黑白）。标记意图即可，具体机位/剪辑留给导演阶段。

> **与导演层的分工**：本节只负责在剧本里埋下"纯视觉建立／零解释"的意图。**手法的正式选定在 S6**——见 `templates/director-handoff.md`「三·补 核心视听手法」，完整武器库（每类手法的效果、适用场景、落到哪些分镜字段）见 `references/director-visual-language.md`「Audio-Visual Device Library」。同一个手法不要在两层各写一套判断标准。

## 八、四张自检清单（覆盖"输出前自检"铁律）

用户要求 `[自检]` 或 Agent 内部静默过检时，按所处步骤调用对应清单：

**自检一 · 核心概念与戏剧动作**
- [ ] 是否建立了"目标 + 冲突"？目标是否合理且急切？
- [ ] 目标和阻碍是否有强烈对抗关系？冲突是否是驱动故事的发动机？
- [ ] 阻碍是否在合理尺度内，而非刻意夸大？
- [ ] 概念是否一句话说清、5 秒画面可呈现（概念纯度）？

**自检二 · 人物塑造与弧光**
- [ ] 外在需求（want）与内在欲望（need）是否清晰且对立？
- [ ] 是否预设了不可逆的内在变化（新常态）？
- [ ] 是否具备矛盾性（表里反差）？行为是否符合前史逻辑？
- [ ] 需要深度的角色是否填了 Ghost/Lie/Flaw，且真能驱动冲突（非形容词）？

**自检三 · 结构与节奏**
- [ ] 骨架方法论是否选定（短片默认四幕；需要升级时是否已告知用户）？
- [ ] 激励事件 / 中点 / 高潮是否明确？每部分是否都推动情节或揭示性格？
- [ ] 是否存在无效情节（只推进剧情却无改变）？
- [ ] 障碍是否递进且不同质？时长预算是否合理？
- [ ] 双轨节奏是否有至少一处错位（情节松+情感重 / 情节紧+情感轻）？

**自检四 · 场景写作与视听语言**
- [ ] 是否有心理描写？（有则 Fail）
- [ ] 是否有括号暗示、解释性台词、说教煽情、AI 腔？（有则 Fail）
- [ ] 是否用画面叙事？对话是否过于直白（缺潜台词）？
- [ ] 台词是否口语化、角色间可分辨？
- [ ] 伏笔是否自然植入（首次出现有合理表面理由）？

## 九、长内容可选模块（仅当项目扩展到长片 / 剧集 / 多段长篇时启用）

> 以下模块默认**不启用**。当项目从"10–15 秒单段"扩展到"多段长篇 / 长片 / 剧集"时，按本段启用，避免短内容被过度工程拖慢。

### 记忆检查点系统
长内容上下文易超限导致前后矛盾。每完成一个段落（P）或序列，生成一份结构化压缩快照（非全文复述）：故事核心（logline / 主题 / 核心戏剧动作）、角色当前状态（物理/情感/已知/想要）、已完成段落摘要（每场一句话＋价值转变）、活跃线索、伏笔状态（已埋未回扣 / 已回扣）、节奏状态（上段情节/情感 → 下段建议）、待写预告。用户跨对话续写时，把检查点贴回即可恢复上下文。

### 弧光预算
长片 / 剧集的弧光是"预算制"——变化量分配到各段/各集，前面的段不能让角色变化太多。比例：前 25% 累计进度不超 15%；至少一次"伪变化后的回退"；65%–85% 是加速区。纯短内容可略。

### 分集大纲（剧集）
剧集先拉通"季度规划 + 分集大纲"再逐集写；每集拆出都要独立成立（Logline 成立），同时服务季度大弧线。集间需有节奏波浪（不能连续 3 集同基调）。
