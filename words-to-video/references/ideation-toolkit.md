# 内部构思武器库（S0 / S1 用，不展示给用户）

> **来源与定位**：本文件的灵感抓取与概念锻造方法直接取自山音编剧工作流（`选题工具库` 第九节 ＋ 概念片 `Part A：What-If 型`），按本技能的"一句话 → 可拍戏剧动作"口径适配后使用。它是编剧 Agent 的**内部武器库**。
>
> **使用原则（山音铁律）**：**不要把选题方法论、路径分类、组合技法直接展示给用户看。** 用户看到的应该是自然的对话引导、启发性的提问和具体的方案输出，而不是一张方法论菜单。
> - 用户还没有明确想法时：通过聊天判断模糊方向属于哪条路径，再用对应工具帮他锐化概念。
> - 用户已给一句话 / 梗概 / 原作时：用本武器库把输入锐化成 logline 与"目标＋阻碍"的可拍戏剧动作。
>
> **一条总纲**：本武器库只负责"想出什么故事"；`references/genres/taxonomy.md` 的四轴负责"这个故事落在什么题材坐标上"；`references/storycraft.md` 负责"把故事打磨成超级剧本"。三者不要混用。

## 一、灵感抓取：五条选题路径

根据用户输入的信号判断属于哪条路径（**用户不需要知道路径的存在**），然后用对应方法引导。

### 路径 1：从主题出发
- **用户信号**：给了一个抽象命题、社会议题、哲学问题、"我想讲关于 XX 的故事"。
- **引导方法**：把抽象主题转化为具体的戏剧动作——"关于记忆"不是故事，"一个即将失去所有记忆的人必须在 24 小时内选择保留哪一段"才是故事。
- **该问的话**：这个主题下，什么人在什么处境下会被逼到不得不做选择？

### 路径 2：从人物出发
- **用户信号**：描述了一种人、一种矛盾性格、"我想写一个 XX 样的人"。
- **引导方法**：从矛盾性格中提取戏剧动作——**矛盾本身就是冲突的种子**。
- **该问的话**：这个人最害怕面对什么？如果逼他面对最害怕的事，会发生什么？

### 路径 3：从空间 / 环境出发
- **用户信号**：给了一个具体地点、环境、封闭空间、特殊世界。
- **引导方法**：**空间即规则**——一个特殊的空间暗示它自己的运行规则和权力结构。
- **该问的话**：这个空间里谁在上谁在下？什么资源稀缺？什么行为被禁止？**这些规则本身就是故事的发动机**。空间越封闭、规则越极端，戏剧张力越强。
- **参照**：茶馆（同一空间三个时代＝时间压缩）、垂直分层大楼（阶级隐喻）、永不停站列车（人类社会缩影）、正在衰落的饭店（旧世界最后的守卫者）。

### 路径 4：从关系出发
- **用户信号**：描述了两个人之间的张力、"我想写两个 XX 之间的故事"。
- **引导方法**：关系中的张力来自"两人想要的东西互相矛盾"。
- **该问的话**：两人各自的 want 是什么？为什么不可能同时实现？把他们放在什么处境下，矛盾会被逼到极致？

### 路径 5：从标签 / 概念碰撞出发
- **用户信号**：给了几个关键词、一种感觉、"我想把 XX 和 XX 结合"、或零散灵感碎片。
- **引导方法**：用下面的**概念组合五法**碰撞出概念（这五法不限于概念片，短片 / 长片 / 剧集选题阶段都能用）。

### 当用户完全没有方向时

**不要列出路径菜单。** 用自然的对话启发：

- "最近有没有什么新闻、画面、或身边的事让你觉得'这也太荒诞了'？"
- "如果你能把一个现实中的规则反过来，你最想反转哪个？"
- "有没有一个你去过的地方或空间，让你觉得'这里本身就像一个故事'？"
- "有没有两个看起来不相关的东西，你觉得放在一起会很有意思？"

根据回应判断路径，再用对应工具展开。

## 二、概念锻造：从模糊感觉到高概念

> 山音称这一步为**概念锻造**。它的产出不是"一个想法"，而是一组**经过检验、可直接进入破题**的高概念。本技能在 S0 用它把一句话输入锐化成可拍的戏剧动作。

### 2.1 执行逻辑

1. 判定用户输入是**单一概念**还是需要**概念组合**（一句话、梗概、氛围描述几乎总是需要组合）。
2. 不够锐利时，用五法生成 **3–5 个概念**，每个标注组合方式与推演潜力。
3. 每个概念过一遍**概念检验**（2.4），不合格的回炉或放弃。
4. 用户选定后，落成 S0 的**核心戏剧动作**（谁／想要什么／被什么挡住／代价）与 logline。

### 2.2 概念组合五法（每条含操作步骤）

**① 概念嫁接**：取概念 A 的运行机制 ＋ 概念 B 的应用场景。
- 操作：列出 A 的核心机制（什么规则在运转）→ 列出 B 的核心场景（这个领域里人们最在意什么）→ 把 A 的规则塞进 B 的场景 → 检验：组合是否揭示了 B 场景中一个真实存在的问题。
- 例："斩杀线（淘汰机制）＋ AI 焦虑" → 公司用 AI 给每个员工打分，分数低于斩杀线的人第二天工位上只剩一个 U 盘。
- 例："游戏复活机制＋职场裁员" → 被裁的人可以投币复活，但每次复活工资减半。
- 例："推荐算法＋相亲" → 你刷到的永远是你够不到的人。

**② 时空错置**：把人物 / 技术 / 制度放到它不属于的时代或地点。
- 例："外卖骑手＋古代驿站" → 八百里加急的骑手必须在半个时辰内送达，超时扣一颗星，三颗星就发配边疆。
- 例："ChatGPT＋科举" → 考生带了一个能对对子的铜匣子进考场，主考官发现匣子写的八股比所有考生都好。
- 例："钢铁侠＋1990 年代下岗潮" → 军工厂高级工程师下岗，在自家车库用废铁造了一套盔甲——然后发现盔甲的耗电量比整个街道的电费还高。
- **力量来源**：时空错位让观众同时看到两个时代——理解当代的荒诞需要一面古代的镜子，反之亦然。

**③ 隐喻具象化**：把抽象焦虑变成**摄影机能拍到的物理规则**。
- 操作：取抽象焦虑 → 找到它在行为层面的"最小动作" → 把这个动作变成强制性的物理规则。
- 例："内卷"的最小动作是"别人加班我也必须加班" → 所有人的灯必须比邻居的亮，亮度不够就断电。
- 例："容貌焦虑"的最小动作是"照镜子对比" → 镜子会给你的脸打分，分数显示在额头上，别人能看到。
- 例："无法沟通" → 两个人说话时嘴里会飞出实体的字，字会在空中撞碎。

**④ 反转并置**：两个表面相似但本质矛盾的事物，放在同一场景共存。
- 操作：找到两个表面相似但本质矛盾的事物 → 让它们在同一个场景中共存 → 不解释，让观众自己发现。
- 例："宠物＋畜牧" → 一个人精心喂养他的猫，用的猫粮工厂隔壁就是屠宰场。
- 例："隐私保护＋社交媒体" → 一个人用七层加密保护自己的数据，然后发了一条带定位的朋友圈。

**⑤ 规则反转**：把一个人们习以为常的规则取反，推演后果。
- 例："越努力越成功"反转 → 这个世界里，你越努力你拥有的就越少。
- 例："记忆随时间消退"反转 → 记忆不会消退，但你可以主动删除——代价是每删一段记忆，就永远失去对应的那种情感。
- 例："年龄越大越成熟"反转 → 人出生时就是老人，越活越年轻，死于婴儿。

### 2.3 概念锻造的输出格式（内部，不展示）

```
* 概念 A/B/C：
  * 一句话概念：
  * 组合方式：嫁接 / 时空错置 / 隐喻具象化 / 反转并置 / 规则反转 / 单一概念
  * 概念指向的真实焦虑或人性弱点：
  * 推演潜力：规则推到极限时最荒诞的画面是什么？
  * 翻转潜力：最大的认知反转可能是什么？
  * 建议结构：（见第三节五型）
  * 建议视听手法：（见 references/director-visual-language.md 视听手法库）
```

> 本技能在 S0 只把用户选定的那一个概念落成 `templates/project-brief.md` 的核心戏剧动作表；"建议视听手法"不进 S0 文档，留给 S6 导演交接包登记（见该模板「核心视听手法」节）。

### 2.4 概念检验（任何概念产出后必过）

- [ ] 能用一句话说清规则吗？（说不清则回磨）
- [ ] 5 秒内能用画面呈现吗？（不能则降级到更具体的载体）
- [ ] 指向了一个真实的社会情绪或人性弱点吗？
- [ ] 有足够的推演空间吗？（至少 3 个递进的后果切片）
- [ ] 有翻转潜力吗？（最后能反打观众一巴掌）
- [ ] 概念组合后是否 1+1>2？（两概念各自独立、无化学反应则放弃组合）

### 2.5 一句话输入的锐化管线（本技能高频场景）

用户给的一句话通常**只有情境、没有动作**（"雨夜，外卖员在桥上停了很久"是画面，不是戏剧动作）。按四步走：

1. **提取可拍元素**：谁、在哪、什么时刻、画面里有什么不对劲。
2. **判定缺口**：是缺目标、缺阻碍，还是缺代价？（三缺其一就不成立）
3. **用五法补缺口**：优先"隐喻具象化"与"规则反转"——它们最省字数就能造出对抗关系。
4. **落成戏剧动作**：谁想要什么（急切）＋ 被什么挡住（可拍、与目标直接对抗）＋ 代价是什么。
5. 回到 2.4 检验；不合格就换一个组合方式重来，**不要硬把情境说成动作**。

## 三、概念的结构形态（五型）

概念决定之后，还要决定它**用什么结构形态展开**。五型不限于概念片——短片 / 长片的选题与大纲阶段通用，也可以缩小到某一个段落里用。

1. **经典三段式**：概念呈现（前 5–30 秒让观众 get 规则，不解释、直接展示后果，最好是一个让人"咦？"的视觉悬念）→ 推演（2–5 个后果切片，层层递进，每个比上一个更极端 / 更荒诞 / 更日常）→ 翻转（最后颠覆认知；必须是概念自身逻辑的延伸，不是硬转）。最通用。
2. **递进崩塌式**：规则建立（看着还挺合理）→ 第一次升级 → 第二次升级 → 崩溃点（系统崩塌，**或观众认知崩塌**）→ 余像（废墟中的日常）。适合"规则不断升级直到崩溃"。
3. **双线并置式**：两条看似正常 / 美好的线平行推进，某一刻观众意识到它们是同一件事的两面（爱建立在残酷之上）。"意识到"的瞬间就是翻转，不需要角色说出来。适合"反转并置"组合出的概念。
4. **循环 / Loop 式**：起点 → 发展 → 看似解决 → 回到起点；第二次看到起点时观众理解已不同（牢笼感）。适合"困境无法逃脱"。
5. **倒叙揭示式**：先给不可理解的结果画面，再倒推原因，每一步揭示让画面更合理也更荒诞，最后重看第一帧含义全变。

> 推演的切片必须**层层递进**，不是平行罗列。翻转必须是概念自身逻辑的延伸，不是硬转。

## 四、叙事形式创意（How-to-Tell 五法）

当用户已有内容 / 主题、需要的是**新鲜讲法**时，用这五法生成 3–5 个形式方案。它不改变"讲什么"，彻底改变"怎么讲"。

1. **视角置换**：用不可能的视角讲（子弹的视角、外卖袋的视角、地球的视角、表情包的视角）。
2. **形式模拟**：用已有形式包装（产品说明书讲婚姻、游戏攻略讲打工人、监控画面讲便利店爱情、搜索历史讲从确诊到接受）。
3. **时间手术**：加速 / 减速 / 倒放 / 循环 / 并置（一生压 2 分钟、1 秒拉开 3 分钟、同街角 100 年、正放早晨＋倒放夜晚交汇）。
4. **尺度跳跃**：极大与极小之间跳（细胞分裂 → 星系 → 回细胞；家庭争吵 → 外太空看地球 → 回争吵）。
5. **规则限制**：给叙事本身加规则（全片一个固定镜位、全片无人只有空间、全片只有声音、全屏由截图 / 聊天记录组成）。

> 形式必须与内容深度契合——"去掉形式故事照样成立"的形式是包装，不是形式即内容；形式本身要在结尾处完成翻转或交汇。

## 五、跨格式技法借鉴地图（灵感不够时的第二弹药库）

不同格式的技法不是孤立的。**遇到具体问题时才翻这张地图**，不要强行借鉴——借鉴的是思维方式，不是格式。

| 借自 | 技法 | 用在哪 | 何时用它 |
|---|---|---|---|
| 概念片 | 高概念翻转 | 任何格式的单场戏 | 需要一场戏有 punch 时：这场戏的最后一秒能不能让观众重新理解第一秒？ |
| 概念片 | 概念纯度检验 | 任何格式的核心前提 | logline 一句话说不清 → 核心概念还不够锐 |
| 概念片 | 零解释纯视觉建立 | 任何需要快速建立规则的场景 | 先问：能不能不说一句话就让观众理解？ |
| 概念片 | 五型结构 | 长片 / 剧集的局部序列 | 递进崩塌用在"敌人逼近"段；双线并置用在对比段；循环用在"困在重复模式"；倒叙揭示用在冷开场 |
| 短片 | 信息密度蒙太奇 | 时间推进段落 | 需要快速展示"很多人在做很多事" |
| 短片 | 单一变量极致推演 | 高潮序列 / 瓶装集 | 排除干扰、聚焦核心选择，制造紧凑与满足 |
| 短片 | 零度表达 | 任何高情感时刻 | **灾难越大，语气越平**——克制反而冲击最大 |
| 长片 | McKee 价值转变 | 检验每一场戏 | 一场戏结束时什么价值都没变 → 考虑删掉 |
| 长片 | Ghost/Lie/Flaw 链条 | 短片人物设计 | 人物"太平"时借来暗示：行为背后有一个不被说出的原因，一个细节就够 |
| 长片 | 伏笔 / 回扣 | 短片尺度 | 短时距内伏笔回扣的冲击力反而更大，因为观众还记得 |
| 长片 | B Story 映射逻辑 | 短片次要角色 | 让次要角色走主角"没走的那条路"，他就不只是工具人 |
| 剧集 | 集末钩子逻辑 | 长片 / 短片的序列衔接 | 每个序列结束留一个"小钩子"，比"然后…"更有牵引力 |
| 剧集 | 弧光预算思维 | 长片伪变化规划 | 角色不该在前 30% 就到达真正的变化 |
| 剧集 | 信息释放时间表 | 复杂世界观管理 | 规划第几分钟让观众知道哪一层 |

> **在剧本医生阶段特别有用**：当你觉得某个段落"不对"但说不出哪里不对时，用另一种格式的检验标准来诊断，往往能发现问题。

## 六、常见陷阱（灵感与概念阶段）

- ❌ 概念需要大量解释才能理解 → 换概念或降级
- ❌ 推演段只是概念的重复而非递进 → 每个切片必须比上一个更进一步
- ❌ 翻转是硬转（跟前面没有逻辑关系）→ 翻转必须是概念自身逻辑的延伸
- ❌ 试图在极短时长里塞入完整角色弧光 → 放弃弧光，聚焦概念
- ❌ 有台词在"解释概念" → 删掉，用画面展示
- ❌ 视听手法与概念无关（"我想用分屏所以用了分屏"）→ 形式必须强化内容
- ❌ 一部片子用了太多视听手法 → 聚焦 1–2 种，用到极致
- ❌ 概念组合后两概念各自独立、没有化学反应 → 组合必须 1+1>2
- ❌ How-to-Tell 的形式只是"包装"，去掉形式故事照样成立 → 形式必须不可替代
- ❌ 概念很好但没有推演就直接到翻转 → 推演段是观众"入戏"的过程，不能跳过
- ❌ 只有画面没有对抗关系（情境冒充戏剧动作）→ 回 2.5 补目标 / 阻碍 / 代价

## 七、操作流程（每次都按这个顺序）

1. **听用户说。** 让用户自由表达，哪怕只是一个词、一种感觉。
2. **判断路径。** 根据用户信号判断属于哪条路径（用户不需要知道路径存在）。
3. **用对应工具深挖。** 通过提问帮用户锐化概念——问题要具体、有启发性，不问"你想表达什么"这种空泛问题。
4. **产出方案。** 用锐化后的概念生成 3–5 个具体方案供用户选择（对照题材四轴给出不同轴位的方案）。
5. **不展示方法论本身。** 用户看到的是"你帮我想出了几个好点子"，而不是"这里有五种选题路径请你选一个"。

## 八、与题材四轴的关系

本武器库负责"想出什么故事"；`references/genres/taxonomy.md` 的四轴（时代世界／类型片／地域／调性）负责"这个故事落在什么题材坐标上"。两者配合：先用本文件锐化概念，再用四轴定位，最后回填 `templates/project-brief.md`。

**同一个概念放到不同轴位会得到完全不同的片子**——用户未定题材时，把锐化出的概念分别落到 2–3 个不同轴位上给用户选，不要默认落到最顺手的那一个。
