# 角色具体化拆解（S4 角色设计方法）

> 作用：在填角色卡之前，把"轻佻的男性""清冷的女生""一个有绅士感的人""赛博朋克的雇佣兵"这类**模糊感觉**，拆成模型能直接执行的**名词或动作**，每个维度单独可替换、可检查。本文件是方法；词库、时代/风格库与示例在 `char-library/`。
>
> 来源：吸收自 `juese-sheji`（角色设计 skill）的"具体化"方法论——形容词→名词化、三层分层、不完美＋生活痕迹、刚柔光谱。仅取其中"角色形容拆解"与"外貌/服饰库"两部分，未引入其人物原型、表情防夸张、群像对照等其它模块。

## 为什么先拆解再填卡

核心规则（见 `char-library/articulate-rules.md`）：**你能把要求说到多细，就能控制到多细；没说出来的维度，模型全部用默认值（众数）替你填。** 形容词是请模型猜，名词是给模型下单。"帅气""轻佻""高级感"会把人拉成一张 AI 平均脸。所以角色设定表之前，必须先"具体化"。

## 步骤

1. **定世界背景与造型体系**：看 `templates/asset-design.md` 〇章的「世界背景」。
   - **古典 / 古装 / 历史向架空** → 服饰查 `char-library/historical/古典形制.md`；场景查 `char-library/historical/architecture.md`、器物查 `char-library/historical/objects.md`（**三份仅这类题材一起加载**，当代未来不加载，否则形制会把画面拽回古代）。
   - **现代 / 科幻 / 架空非历史** → 服饰查 `char-library/styles/服装风格.md`（47 个通用/现代审美风格）＋ `char-library/styles/时代与类型.md`（中国/欧美时代、亚文化、制服、类型片世界，**含赛博朋克/太空科幻/末日废土/中世纪奇幻**）＋ `char-library/styles/人群与身份.md`（一类人在生活里通常的样子）。
   - 造型体系对应表里的「古典形制／现代服装／科幻功能服」三选一。
2. **一句话定人**：身份＋处境＋他想要什么（1–2 行）；剧本里没有的标「补」。
3. **查库，逐维度定写法**：按 `char-library/styles/索引.md` 判断用户说法属于哪一类（一种穿衣风格 / 一个时代或圈子 / 一类人或身份 / 一种气质），常常叠着用（"一个有绅士感的老教授"＝人群＋风格＋生活痕迹）。从对应库挑 **5–8 条**最能说明这个人的，再按 `char-library/dimensions/04-服装.md` 往下切一层（"粗花呢西装"→三粒扣、人字纹、手肘磨亮、内搭浅蓝牛津衬衫）。**挑、不整条照抄**（照抄＝刻板）。逐维度写法见 `char-library/dimensions/` 九份词库（脸/发型/配饰/服装/身体姿态/生活痕迹/微表情/说话方式/精神状态）。
4. **形容词→名词化（铁则）**：把每个伞形词拆到具体维度（伞形词清单见 `char-library/articulate-rules.md` 第 1 节；"不写判断写形态"见第 3 节）。例：
   - "油腻" → 额头和鼻翼油光、头发打太多发胶结成束、衬衫领口发黄、小指留长指甲。
   - "苦相" → 不写情绪，写结果：眉骨前凸、脖子往前缩、圆肩、肤色不均蜡黄、额角一道没长好的伤口。
   - 一个情绪词都不用，这个人吃过什么苦、是什么样的人，脸和身体已经替他说了。
5. **三层标注**（articulate-rules 第 7 节）：每一行标 **身份 / 造型 / 状态**。
   - **身份**：跨场跨段不变（脸型骨相、痣/疤/饺子耳/断眉、天生发质发色、常年生活痕迹、长期不摘配饰）；写进每个镜头与角色卡；出图后漂了最严重。
   - **造型**：这一套 Look，同一个人会换（发型打理、衣服鞋、当天配饰、妆、穿法）；按场次换整套（造型A/B/C）。
   - **状态**：随剧情变化的临时痕迹（淋湿、受伤、脏污、疲惫黑眼圈、哭过的眼）；只写进生效那几镜，不进角色卡锁定段。
   - 拿不准：下一场换了衣服它还在不在？在＝身份；跟着衣服走＝造型；过几场就没＝状态。
6. **不完美＋生活痕迹**（articulate-rules 第 2 节）：至少 **2 处不完美**（一颗痣写位置、一道浅抬头纹、袖口起球、指甲边倒刺；写局部不写铺满）；至少 **1–2 处**职业/经历留在身体上的印子（拳击手饺子耳、农民虎口厚茧、健身人脸颊脂肪少）。暗示性写法，和小传对得上，对不上就是穿帮。衣服同理：写清旧在哪、脏在哪（做旧见 `char-library/dimensions/04-服装.md`）。
7. **刚柔定位**（见 `char-library/soft-hard-axis.md`）：把各维度放到刚（硬/直线/棱角/往外占）↔ 柔（软/曲线/圆钝/往里收）光谱，分**底色（身份层）/ 推向（造型层）/ 习惯**三层。"柔和""硬朗""温润"按那份文件拆成名词。顺推强化、逆推反差；主角至少留一处和整体方向相反，避免所有项推到同一端变成刻板。各项打架又说不出理由的，回第 3 步改。
8. **形容词残留检查**：把总表里剩下的形容词圈出来，逐个换成名词或动作；换不出来的列给用户，说明"这里需要他自己来定"。

## 落到角色卡

拆解结果按 `templates/asset-design.md` 的「角色设定」表与「六行信息表」填写。**六行信息表 schema 不变**（姓名／时代或世界·身份／年龄·籍贯或出身／性格／外貌·发型／着装·气质）——本方法只是把"外貌·发型""着装·气质"这两格写得更具体、可生成，并多出"体型/脸型骨相""发型/面容/皮肤""造型体系""配色/材质""气质/习惯动作"等中间列供过程使用。**不新增卡内字段、不动五区版式、不动下游故事板 schema。**

## 边界

- 本方法只服务于 **S4 角色设定文字与角色卡内容**，不进入场景卡、道具卡、故事板 schema。
- 表情与精神状态见 `char-library/dimensions/07-微表情.md`、`09-精神状态.md`：写进镜头 prompt 与妆发卡、连戏表，**不进角色卡锁定段**。
- 出图后的一致性审见 `templates/image-review.md`（与 juese-sheji 的"漂移清单"同一思路：哪些写了的东西被模型改回平均值，怎么修）。
- 声音（语速/语调/音色/口头禅）只放说话方式参考，作台词与表演的文字参考，不写进生图/生视频 prompt。
