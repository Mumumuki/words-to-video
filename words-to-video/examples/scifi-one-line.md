# 样例：一句话 → 可拍剧本（科幻）

> 用途：验收 `original` 模式在科幻题材下能否先立规则、再写故事，且结局不靠临时新增设定。
> 本样例只展示**第一至第三步**的文本层产物，不含资产、分镜、生图与故事板。

## 输入

> 永久黄昏的轨道城里，一名记忆修复师发现所有居民都在重复同一天。

## 第零步｜破题与核心动作

### 方案候选（先给 3 个，用户选定后再往下走）

> 一句话进来时先按山音口径出 3–5 个方案——**每个方案都是一条完整的戏剧动作**。用户选定后，才把它的四项填进下面的表并锁定。

- **方案 A**：主角 记忆修复师／目标 停下整座城的重置／阻碍 唯一方法是删掉她自己最想留住的记忆／logline 唯一记得真相的技师，要用自己最想留住的记忆换全城人的明天
- **方案 B**：主角 记忆修复师／目标 保住自己那段记忆／阻碍 只要她不阻止重置，明天所有人（包括她）又会回到原点／logline 她选择不救这座城，代价是从今天起独自记住所有人的重复
- **方案 C**：主角 一名普通居民／目标 在重置前把一句话传给明天的自己／阻碍 系统不允许任何"跨日"的记忆残留／logline 一个不知道自己被困住的人，想给明天的自己留一句话

> **本样例走方案 A**（代价最硬：要救城就得失去自己最想留住的东西）。方案 B/C 是同一世界的另外两个轴位——**先给选项再定，是这个技能不退化成"给一句话找借口"的关键**。

### 核心戏剧动作

| 项 | 内容 |
|---|---|
| 谁 | 记忆修复师（靠修复他人记忆为生） |
| 想要什么 | 停下整座城的重置——她是唯一记得"所有人都在重复同一天"的人 |
| 被什么挡住 | 重置由系统执行，停下它的唯一方法是删掉一段她自己的记忆 |
| 代价是什么 | 要救这座城，她必须删掉自己唯一想留住的那段记忆 |

> "所有人都在重复同一天"是**设定**，"要停下它就得删掉自己最想留住的记忆"才是**戏剧动作**。科幻设定最容易停在"发现真相→关掉机器→天亮"的通用解法——破题时必须先把代价定死，否则后面每一个节拍都会失去方向。

### 项目定义

| 字段 | 内容 |
|---|---|
| 来源形态 | `original` |
| 来源类型 | `one_line` |
| logline | 一个靠修复他人记忆为生的技师，发现整座城每天在同一刻重置，而她是唯一记得的人；要停下重置，她必须删掉自己唯一想留住的那段记忆 |
| 题材（四轴） | 时代世界：近未来架空（永久黄昏的轨道城）／类型片：悬疑＋思辨／地域：架空·轨道城（东亚城市肌理）／调性：冷·干燥·缓慢逼近 |
| 题材包 | `scifi`（只为拿"科技必须先定四件事"的清单，世界规则的写法见下） |
| 目标时长 | 180 秒（160–190 秒可浮动） |
| 画幅 | 16:9 |
| 视频内容类型 | `剧情演绎` |
| 调性 | 冷、干燥、缓慢逼近 |
| 结局倾向 | 苦涩闭合 |
| 必须保留 | 永久黄昏、轨道城、记忆修复师、所有人重复同一天 |
| 禁止出现 | 时间旅行机器、外星人、救世主叙事 |

## 第一步｜梗概草稿与容量判断

### 梗概（一段话）

> 永久黄昏的轨道城，记忆修复师每天替别人修补记忆，却发现整座城在同一刻重置——只有她记得。她顺着重置的缝隙往上查，发现重置不是故障：系统在靠删掉一个人的记忆来维持运转，而那个"一个人"是她自己。要停下重置，她必须删掉自己唯一想留住的那段。结尾她坐进修复椅，天没有亮——黄昏继续，城继续转，只是她不再记得自己为什么留下。

> 这段先给用户确认走向与气质，认可后再建世界与人物。

- 容量：一句话已给出强设定，但没有人物动机与代价，需要补（见核心戏剧动作）。
- 风险提示：本句最容易写成"发现真相→关掉机器→天亮"的通用解法，必须先把代价定死。
- 参考图状态：无。

## 第二步｜人物深度与世界观（摘要）

### 世界规则（按"科技等级 → 能源 → 社会 → 日常"顺序）

| 编号 | 规则 | 类型 | 标注 | 如何约束行动 |
|---|---|---|---|---|
| W01 | 记忆可被提取、编辑、回写，但**不能创造**，只能重组已有的 | 技术 | `[创作]` | 修复师只能删减与拼接，所以"恢复真相"永远不完整 |
| W02 | 每次编辑会留下**衰减痕**：被编辑过的人对某些具体细节永久失感（尝不出咸、认不出某种颜色） | 技术 | `[创作]` | 城市里所有人都带着某种缺失，可被看见，也可被利用 |
| W03 | 城的能源来自潮汐锁定恒星面的光帆阵列，只有一段固定功率，日落后不再补充 | 能源 | `[创作]` | 大规模计算必须排队；重置本身耗掉全城当日余量，因此没有人有余力同时做别的 |
| W04 | 城务署的"日班"制度：每天同一时刻交接，交接记录由机器写，人只签字 | 制度 | `[创作]` | 没有人真正读过记录，所以重置无人发现 |
| W05 | 修复师执业需登记被编辑者姓名，登记表是唯一的"跨日证据" | 社会 | `[创作]` | 女主能查出重复，只能靠自己的登记表 |

**推演检查**：W02 是第二层后果（编辑技术产生了"失感者"这一群体与相关职业），因此城里的日常必须是"所有人都缺点什么"，不能只是背景干净漂亮。

### 人物

| 项 | 女主（修复师） | 城务署职员 |
|---|---|---|
| want | 弄清自己为什么记得昨天 | 让每一天顺利交接 |
| need | 承认她想留住的不是真相，是一个人 | 承认自己也在重复 |
| 阻力 | 每次查证都要消耗她的记忆额度 | 制度不允许她调阅跨日记录 |
| 弧光 | 从"我要真相"到"我删掉真相，留下那个人" | 不变，成为最后的阻力 |

## 第三步｜结构大纲 → 场景拆解 → 场景写作 → 剧本医生

### 结构选型（先定骨架，再填拍）

选 **McKee 价值转变＋STC 内在节拍，落为 6 拍**；价值轴锁定「真相 ↔ 代价」，且**代价方向为负**——结尾取回的是世界（光帆余量），付出的是人（她删掉那个人）。**不选** Story Circle——主角始终在同一系统内，无"带着所得回归"的环；**不选**纯悬念揭示结构——本片的重量在"解法必须由已有规则推出"，不在"最后揭晓什么"。

### 节拍表（6 拍）

| # | 节拍 | 变化 |
|---|---|---|
| 1 | 黄昏光下，女主修复一位老人"尝不出咸"的记忆 | 建立世界与代价 |
| 2 | 她翻登记表，发现同一个名字连续出现 | 信息 |
| 3 | 她试探同事，对方对昨天的提问答得一字不差 | 恐怖感 |
| 4 | 她在交接记录里找到全城余量被同一件事消耗的曲线 | 权力：她拿到了证据 |
| 5 | 城务署职员告诉她：停下重置需要一段"足够重的记忆"作抵押 | 规则回收，代价显形 |
| 6 | 她删掉那个人，天没有亮，但光帆的余量恢复了 | 苦涩闭合 |

### 关键规则回收

第 5 拍的"抵押"不是新发明——它由 W01（只能重组，不能创造）与 W03（能源有限）共同推出：**要从系统里取出一样东西，必须放进去等重的东西。** 剧本的解法必须能追到已建立的规则，否则本条验收不通过。

### 剧本医生（S3 自检）

按 `references/storycraft.md` 第六节做诊断、第八节四张清单覆盖输出前自检（长内容项不适用）：

- **价值转变**：拍 1 到拍 6 沿「胜任 → 察觉 → 取证 → 付出」走完，价值由正转负（世界得救、人没了）——转变明确，不是暧昧收尾。
- **鸿沟**：拍 3 她试探同事，期望得到破绽，结果对方答得一字不差——落差直接产出恐怖感，不靠配乐与台词说明。
- **危机选择**：拍 6 是真正的选择（删或不删），且两个选项都要付代价；她选了"世界"这一侧，与她前五拍的行为一致，不突兀。
- **无效情节审计**：六拍各改变一项；拍 2 的"同一个名字连续出现"同时是伏笔，拍 5 回收——无悬空伏笔。
- **规则闭环**：解法（抵押一段足够重的记忆）由 W01＋W03 共同推出，**不是临时新增设定**——这是本片最容易被写崩的地方，见上节「关键规则回收」。
- **开场钩子**：拍 1 用"修复一位老人尝不出咸的记忆"开场，既给世界观（记忆可被修复）又给具体疑问（为什么是"咸"），不靠旁白交代科技等级。

## 验收要点

- 判定为 `original / one_line`，未出现"原文"字段
- 科技等级写明"不能创造记忆"，因此结尾不能靠"恢复全部记忆"解决
- 结局的代价来自 W01＋W03，无临时新增设定
- 世界规则落到了日常细节（老人尝不出咸），不是背景装饰
