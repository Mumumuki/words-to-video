# 样例：一句话 → 可拍剧本（现代悬疑）

> 用途：验收 `original` 模式能否只凭一句话产出项目定义、世界规则、人物与剧本。
> 本样例只展示**第一至第三步**的文本层产物，不含资产、分镜、生图与故事板。
> 实际执行时 G1–G3 是检查点（展示即继续，不停），只在 G4 停下；此处为压缩展示，省略了修订轮次。

## 输入

> 深夜便利店，店员发现每天凌晨三点来买同一瓶水的男人，从来不照镜子。

## 第零步｜破题与核心动作

### 方案候选（先给 3 个，用户选定后再往下走）

> 一句话进来时先按山音口径出 3–5 个方案——**每个方案都是一条完整的戏剧动作，不是同一个故事的三个角度**。用户选定后，才把它的四项填进下面的表并锁定。

- **方案 A**：主角 夜班店员／目标 弄清常客为什么不照镜子／阻碍 对方不解释、一试探就逼近不该问的问题／logline 一个店员想弄清常客避开镜子的原因，弄清后必须决定要不要让他继续来
- **方案 B**：主角 那个男人／目标 在被人认出来之前买完水离开／阻碍 店员今晚第一次主动搭话／logline 一个不能被照见的人，必须在店员认出他之前离开便利店
- **方案 C**：主角 店员／目标 保住这份夜班工作／阻碍 好奇心逼她在"照规矩做事"与"问出真相"之间选一个／logline 一个店员为了保住工作必须放弃追问，而她已经问出口了

> **本样例走方案 A**（视角落在追问者身上，悬念由观众与她同步获得）。方案 B 是同一个素材的"反打"——把主角换成被追问者，成本一样但气质完全不同。**这一步必须真的给出不同选项，否则破题就退化成给一句话找借口。**

### 核心戏剧动作

| 项 | 内容 |
|---|---|
| 谁 | 夜班店员 |
| 想要什么 | 弄清这个每天凌晨三点来买同一瓶水的男人，为什么从来不照镜子 |
| 被什么挡住 | 对方不解释、不回应，且她一试探就逼近一个不该被问的问题 |
| 代价是什么 | 弄清之后，她必须决定要不要让他继续来——知道真相意味着要承担处置 |

> 原句"从来不照镜子"是个**反常动作**，不是戏剧动作。破题要把它翻成"谁想要什么＋被什么挡住"：店员的好奇是目标，对方的沉默是阻碍，而"弄清之后怎么办"是代价。少了代价，这场戏就没有张力。

### 项目定义

| 字段 | 内容 |
|---|---|
| 来源形态 | `original`（只有一句话，无原作可依） |
| 来源类型 | `one_line` |
| logline | 一个夜班店员想弄清常客为什么避开店里那面镜子，弄清之后她必须决定要不要让他继续来 |
| 题材（四轴） | 时代世界：当代都市（深夜便利店）／类型片：轻悬疑／地域：中国·城市／调性：冷·安静·克制 |
| 题材包 | 无（四轴已写全；`modern.md` 的"现代戏的紧张感来自被人看见"已落进 W02） |
| 目标时长 | 150 秒（140–170 秒可浮动） |
| 画幅 | 16:9 |
| 视频内容类型 | `剧情演绎` |
| 调性 | 冷、安静、克制 |
| 结局倾向 | 留白 |
| 必须保留 | 凌晨三点、同一瓶水、不照镜子 |
| 禁止出现 | 鬼怪实体、血腥、超能力解释 |
| 明确不做 | 不要旁白 |

**用户输入是唯一硬约束**：上述三项即为全部 `[来源]`，其余皆为 `[创作]`。

## 第一步｜梗概草稿与容量判断

### 梗概（一段话）

> 深夜便利店，夜班店员注意到：每天凌晨三点来买同一瓶水的男人，从来不照镜子——不是没看见，是绕着走。她开始试探，把镜子擦得更亮、把货架换位、在他必经的动线上多放一面。他每次都避开。直到这一晚，她直接把那瓶水递到镜子前。他接过去，抬头，第一次看向镜面。全片没有解释他看到了什么——镜头停在她的反应上，留白。

> 这段先给用户确认走向与气质，认可后再建人物与世界。

- 容量：一句话只够一个"发现"的动作，需补一个"试探"与一个"代价"（见核心戏剧动作）。
- 参考图状态：无。

## 第二步｜人物深度与世界观（摘要）

### 世界规则

| 编号 | 规则 | 类型 | 标注 | 如何约束行动 |
|---|---|---|---|---|
| W01 | 便利店只有一处镜子，在收银台侧面的防损凸面镜，能照到进门的人 | 物理 | `[创作]` | 男人每次进门都会绕到货架另一侧，因此店员能看见他的路线 |
| W02 | 凌晨三点到四点只有一个店员值班，报警后巡警最快八分钟到 | 制度 | `[创作]` | 她不能靠外部救援，必须自己决定 |
| W03 | 店内监控只保留七天，且只有一个角度 | 技术 | `[创作]` | 想查旧记录必须当天决定，过期即无 |

### 人物

| 项 | 店员（林） | 男人 |
|---|---|---|
| 身份 | 夜班店员，白天在准备考试 | 不详，穿同一件深色外套 |
| want | 让这个夜班不出事 | 买到那瓶水，不被注意 |
| need | 确认自己有能力判断一个人的好坏 | 有人不追问 |
| 阻力 | 店里只有她一个人，且她没有权限赶客 | 她的注视本身就是威胁 |
| 弧光 | 从"想弄清"到"选择不问" | 不变，但最后多了一个动作 |

### 视觉连续性锁

- 男人：深色外套、右手拎同一只塑料袋、左手始终空着
- 林：店员马甲、工牌反戴（遮住姓名）
- 场景：冷白顶灯＋门外招牌橘光，收银台在画面右侧

## 第三步｜结构大纲 → 场景拆解 → 场景写作 → 剧本医生

### 结构选型（先定骨架，再填拍）

选 **STC 内在节拍，精简为 5 拍**；价值轴锁定单一轴「回避 ↔ 被看见」。**不选**完整 15 拍 STC——本片是单场、单一动作，15 拍会把一个瞬间拉成空转；**不选** Story Circle——人物无空间位移，硬写一"环"会造出虚假的旅程感。`original` 模式来源只有一句话，骨架由我们选定，不受原作事件约束。

### 节拍表（5 拍）

| # | 节拍 | 变化 |
|---|---|---|
| 1 | 三点整，男人进门，绕过镜子，拿同一瓶水 | 建立规律 |
| 2 | 林第一次留意：他从不抬头 | 信息 |
| 3 | 林故意把镜子擦亮，男人改走另一条道 | 权力：她开始试探 |
| 4 | 林说"你后面有镜子"，男人第一次停下 | 情绪峰值 |
| 5 | 男人结账，把塑料袋换成左手，走出去 | 物理状态＋留白 |

### 剧本片段（第 4 拍）

```text
内景 便利店 夜

冷白顶灯。收银台的凸面镜里，男人正低头看货架。

林把抹布放下。
        林
    你后面有镜子。

男人停住。塑料袋在他右手里轻轻响了一下。
他没有转身，只是把头低得更低了一点。

        男人
    我知道。

他把水放到台面上。瓶身上有一层水汽，像刚从冷柜里拿出来很久。
```

### 剧本医生（S3 自检）

按 `references/storycraft.md` 第六节做诊断、第八节四张清单覆盖输出前自检（长内容项不适用）：

- **价值转变**：拍 1 到拍 5 沿「回避 → 被看见 → 仍回避」走完，末拍没有和解，只留物理痕迹（换手、走出去）——转变成立且未闭合过满。
- **鸿沟**：拍 3 她擦亮镜子，期望他抬头，结果他改走另一条道——期望与结果的落差由动作演出，无一句解释。
- **危机选择**：拍 4 她开口是主动选择（可以不说的），代价是暴露自己在观察他。
- **无效情节审计**：五拍各改变一项（规律／信息／权力／情绪峰值／物理状态），无"只是交代"的拍。
- **开场钩子**：拍 1 直接给"绕过镜子、拿同一瓶水"的重复动作，观众立刻产生"他为什么躲镜子"的具体疑问——不靠旁白交代。
- **台词检查**：全片只有两句台词，"我知道"是潜台词（他知道她在看他），无解释性台词、无心理描写。

## 验收要点

- 判定为 `original / one_line`，没有出现"原文"字段
- 三条世界规则各自约束过一次具体行动，不是背景装饰
- want 与 need 不同，阻力可拍
- 150 秒容量成立，五个节拍各含一次变化
- 结局不解释超自然，靠一个动作收束
